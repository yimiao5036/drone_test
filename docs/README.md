## 5. 提交前检查（强制）

```bash
python3 tools/check_docs.py          # 基线/链接/模块文档一致性
python3 tools/check_docs.py --changed # 按 git 改动列出应检查的文档
```

然后：

1. 更新 [`开发进度.md`](开发进度.md)（当前状态/门禁/最近变更）；
2. 如属里程碑，在 [`开发历史.md`](开发历史.md) 顶部追加一条；
3. 按第 4 节矩阵更新模块文档、数据接口、故障排查；
4. 测试数量变化时，更新本文件「当前基线」和下面 9 处；
5. 在 WSL2 Ubuntu 24.04 编译并跑 `ctest`。

## 7. 归档规则

- 不再参与日常维护、但仍有追溯价值的文档移入 `docs/archive/`，并在
  [`archive/README.md`](archive/README.md) 登记；
- 纯重复且无追溯价值的内容可合并后删除；
- 归档文档的链接可能停留在历史路径，不作为日常维护对象；当前文档不得指向已不存在的路径。
