## 三、关键技术决策

- 视频帧用 `Topic` 发布**内存池 RAII 句柄**而非像素数据，多订阅者零拷贝共享；底层缓冲最后引用释放时归还内存池。
- 解码输出直接走 RGA 写入 RKNN 预分配输入内存（BGR→RGB + letterbox 一次完成），避免 CPU 色彩转换。
- 原型为单线程串行（解码→推理→编码），正式工程必须拆独立线程 + Topic 解耦才能逼近 25fps。
