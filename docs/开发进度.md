## 6. 最近变更（2026-10-21）

- 捕网执行器接入 ACK 复位时序：触发 ACK 后保持 1.5s → 复位 → 复位 ACK + settle → Ready；
- 无 ACK/非 ACCEPTED/等待期间断连/触发 3s 未入队 → S16 FAILSAFE、bit4 告警、清空待发命令、停发控制意图；
