符号表与公式（二维速度制导）
提前量：lead_m = 额外提前量(m) + (距离自适应 ? min(0.06·(dObs−R), 2 m) : 0)；lead_s = lead_m / max(0.5,|v_t|)
瞄准点 a = 估计点按 (链路时延 + lead_s) 前视到"现在"再叠加提前量；速度匹配 t_go=0，停车模式另加碰撞三角形提前
视线 r = a − 飞机位置, d̂ = r/|r|, dAim = |r|；刹车包络用控制器可见的估计距离 dObs，不用 dAim
分相位调度（固定开启）：a_term_eff = max(a_term, max(|â_t|, needHold) + 0.5)；w = clamp((dObs−8)/4, 0, 1) 且以 ≤0.8/s 变速
a_plan(s) = a_term_eff + (a_plan − a_term_eff)·w；有效加速度 a_eff = min(a_plan(s), a_phys, √(a_phys²−a_lat²), slew_eff)
制动包络：a_d_eff = min(a_d(s), a_term_eff)/1.3；u_close 由 a_d_eff 与 jerk 制动距离反解，末端在 R−0.1 m 用有符号比例反馈
v_des = v_t + u_close·d̂（速度匹配）；|v_des| ≤ V_body，u ≤ √(V_body²−v_t⊥²) − v_t∥（横向速度超过上限时无完整匹配解）
动态预算：a_side = â_t⊥ + u·λ̇，a_rad = √max(0, a_eff² − a_side²)；相对加/减速预算 = max(0, a_rad↑ − â_t∥) / max(0, a_rad↓ + â_t∥)
转弯约束 u_extra ≤ max(0, 0.8·min(a_eff↑,a_eff↓) − |â_t⊥|)/|λ̇|，λ̇≈0 时不约束；只削额外接近，不削目标速度前馈
急停预留 B>0：另按 a_target∥ ≥ −B 收紧制动预算并计入采样/传输反应距离；0.5 m 只是该一维模型的几何余量，不是二维安全证明
J>0 时制动距离含加速度回收；硬速度上限优先，发生安全裁剪时不保证 jerk（裁剪次数显示在诊断行）
穿透 = 失败判据：d < 0.5 m 置粘性标记并计数，判词首条报"判定为撞击（失败）"（演示无碰撞模型）
停滞 / 提能力：4 s 内无 ≥1 m 实质进展、或能力受限、或已穿透 → 规划加速度按 0.5 m/s²/s 抬向 a_phys，并把 slew 限幅放宽到提升后的规划值
三个对照体：蓝 = 设计；红 = 零余量（V=|v_t|，按定义永不收敛）；绿 = 纯比例尾追（u = k(dAim−R)，k=0.6 固定，速度上限用满）
刹车示意圆只在半径 ≤ 视口对角线时绘制（预算≈0 时制动距离可达 1e7 m，大半径虚线圆弧会让 GPU 单帧卡 100~370 ms）
几何交接示意（假设完美朝向与检测；创新仅用位置 KF 残差，不能替代真实视觉验证）：LOCKED 连续 10 帧 + 斜距 ≤7.95 m（双目测距）+ 俯仰 ≤5.24°（FOV 10.24° − 5° 余量）+ 创新 ≤3 m；3 m/0.5 m/s 只是到点告警
dTruth飞机到目标真值的距离，仅用于仿真图表和捕获评价
dObs飞机到估计/预测位置的距离，控制器可见量（刹车包络用它）
dAim飞机到瞄准点的距离，制导方向按它归一
r, d̂飞机→瞄准点的向量与单位方向
v_t目标速度矢量，来自所选「目标位置来源」
v_t∥目标速度沿视线的有符号分量（后退为正，迎面为负）
v_t⊥目标速度垂直视线分量（绕圈/蛇形的主力）
t_go碰撞三角形的接触时间，夹紧 ≤4 s；速度匹配模式取 0
V_body机体水平速度上限（滑块为 0 时按规划 6 m/s）
u_close沿视线的相对接近速度（设计机=制动曲线反解；绿机=比例 k(dAim−R)）
k绿机（纯比例尾追基线）的比例增益，固定 0.6 1/s
R到点告警半径 3 m；控制间距 R−0.1 m（到点判据仍是 3 m）
dz, vz目标高度差 / 机体垂直速度（容差 2 m，限速 2 m/s、限加速度 2 m/s²）
a_phys机体物理加速度上限：只封顶（plant 夹在这里），剖面由规划值决定
a_plan远段规划加速度；近段改用 a_term_eff，中间按 w 过渡
a_term近段/末端规划加速度的下限（面板滑块，默认 1.5）
a_term_effmax(a_term, 目标机动需求+0.5)：目标需求更大时自动抬升，近段不再被饿死
â_t目标加速度估计：仅在收到新速度样本时差分并低通；不读取仿真真值
needHold目标机动需求的单调峰值保持（蛇形加速度过零时不把近段下限放回去）
w分相位过渡权重 (dObs−8)/4 夹 0~1，速率限幅 0.8/s（消除 8~12 m 抖动）
slew指令加速度上限（实际下发力约束）；a_plan 大于它时只剩它在起作用
slew_eff提能力生效时的 slew：放宽到 max(slew, 提升后的规划值)，否则提 a_plan 无效
a_eff有效加速度 = min(a_plan(s), a_phys, √(a_phys²−a_lat²), slew_eff)
a_side动态侧向需求 = â_t⊥ + u·λ̇，加速度圆里先扣掉它再给纵向
a_rad加速度圆剩余径向能力 √max(0, a_eff² − a_side²)
u_turn转弯约束：限制 u·|λ̇|，只削额外接近速度，不削目标速度前馈
v_ref / v实际二维速度指令的模长 / 飞机当前速度矢量（含方向滞后）
v_c沿瞄准线的接近率 = (v−v_ff)·d̂；≥0 才在缩小瞄准距离
d_brake局部制动距离读数：控制间距 + 一拍反应 + 制动距离；减速度预算≈0 时显示"不可行"
envelope目标沿视线速度 + 制动距离反解的接近速度；含 jerk 与末端比例收敛
lead_m提前量（米）= 额外提前量 + 距离自适应 min(0.06·(dObs−R), 2 m)
lead_s提前量（秒）= lead_m / max(0.5, |v_t|)，叠加在时延补偿之后
时延补偿点估计点按链路时延前视到"现在"的点（不含任何提前量）
瞄准点时延补偿点 + v_t·lead_s（+ v_t·t_go，仅停车模式），控制器与画布共用
制导线设计机→瞄准点（蓝虚线）：控制器真正追的方向
视线设计机→真值目标（灰细虚线）：只用于"视线距离 d"读数与评价
穿透d < 0.5 m 视为撞击：粘性标记 + 判词首条"判定为撞击（失败）"
穿透次数逐段进入计一次（penetrationEpisodes），重跑才清
停滞4 s 内没有 ≥1 m 的实质进展且未到点（擦身而过不算进展）
boostT / +a提能力累计计时（4 s 起抬）/ 当前提升量（0.5 m/s²/s，抬向 a_phys）
急停预留 B已知的目标最大内向加速度界；0=只响应观测，静止目标未观测到运动时不预留
lag「参考点领先」：位置设定点与飞机的距离
σ_a卡尔曼过程噪声：目标加速度标准差（机载 8.0 m/s²）
Jjerk 上限（m/s³）：让指令加速度连续；开启后制动距离要计入加速度回收
零余量对照红机：V=|v_t|，稳态接近速率 ≡ 0（按定义不收敛，不是追击律）
纯尾追基线绿机：u=k(dAim−R)、速度上限用满，能到点但没有制动包络
