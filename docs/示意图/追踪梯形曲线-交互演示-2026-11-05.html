距离 d(t)：设计 vs 无余量　绿虚线 = 到点半径 3 m
设计机速度（25 s 滚动窗）：实际 vs 参考剖面　底色 = 加速 / 巡航 / 减速 / 匹配
符号表与公式（比例接近律）
瞄准点 a = 目标位置 + v_t·t_go　　视线 r = a − 飞机位置, d̂ = r/|r|, dAim = |r|
t_go = [(r·v_t) + √((r·v_t)² + (Vmax²−v_t²)|r|²)] / (Vmax²−v_t²)，夹紧 t_go ≤ 4 s、提前距离 ≤ min(0.5·d, Vmax·0.5 s)
u = clamp(k·(dAim − R), 0, Vmax)　v_turn = a_lat·dAim / v_t⊥　v_ref = clamp(v_t∥ + u, 0, min(Vmax, v_turn))
飞机：v̇ = clamp((v_ref·d̂ − v)/dt, −a_d, +a_a)　　位置设定点 = 飞机 + d̂·min(6 m, v_ref·0.3 s)（一阶跟随）
d飞机到目标真实位置的距离（读数用）
dAim飞机到瞄准点的距离（制导用，≥ d）
r, d̂飞机→瞄准点的向量与单位方向
v_t目标速度矢量，来自所选「目标位置来源」
v_t∥目标速度沿视线分量（后退为正；包络只补偿这部分）
v_t⊥目标速度垂直视线分量（绕圈/蛇形的主力）
t_go碰撞三角形解出的接触时间，夹紧 ≤ 4 s
Vmax规划速度上限（上限滑块为 0 时取 6 m/s）
k比例增益 1/s：误差 1 m → 0.6 m/s 额外接近速度
u沿视线的额外接近速度 u = k(dAim − R)
R到点半径 3 m（进圈且接近率够小才算到位）
a_lat可用加速度（加速 a_a / 减速 a_d）
v_turn转弯约束上限 v ≤ a_lat·dAim/v_t⊥
v_ref沿视线的参考速度（飞机要跟的量）
v飞机当前速度矢量（含方向滞后）
v_c接近率 = v·d̂ − v_t∥；≥0 才在缩小距离
d_brake当前速度刹到末端速度所需距离（×1.3 + 0.5 m 余量）
envelope刹车包络 v_t∥ + √(2a_d(d−R))，梯形律用它切减速
lag「参考点领先」：位置设定点与飞机的距离
σ_a卡尔曼过程噪声：目标加速度标准差（机载 8.0 m/s²）
