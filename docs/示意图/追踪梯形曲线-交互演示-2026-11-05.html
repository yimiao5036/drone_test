距离 d(t)：设计 vs 无余量　绿虚线 = 到点半径 3 m
设计机速度（25 s 滚动窗）：实际 vs 参考剖面　底色 = 加速 / 巡航 / 减速 / 匹配
切向加速度 a_t(t)：实际 vs 指令（沿速度方向，正=加速/负=减速；虚线 = ±上限）
符号表与公式（二维速度制导）
瞄准点 a = 目标估计位置 + v_t·t_go（仅 end=stop）；end=match 时 t_go=0，瞄准点就是预测到"现在"的目标位置
视线 r = a − 飞机位置, d̂ = r/|r|, dAim = |r|；刹车距离用真实距离 dObs，不用 dAim
(Vmax²−v_t²)t_go² − 2(r·v_t)t_go − |r|² = 0，取最小正根并夹紧 t_go ≤ 4 s、提前距离 ≤ min(0.5·dObs, Vmax·0.5 s)
制动曲线：u_close = min(V_catch, √(2·(a_d/1.3)·max(dObs−R,0)))　比例接近：u_close = clamp(k(dAim−R), 0, Vmax)
v_des = v_ff + u_close·d̂，速度匹配时 v_ff=v_t（完整二维矢量，含横向分量），减到 0 时 v_ff=0
|v_des| ≤ min(V_body, a_lat·dAim/v_t⊥)；
指令平滑：|a_cmd| ≤ slew（指令加速度上限）且 |ȧ_cmd| ≤ J（jerk）；飞机加速度再受 a_a/a_d 限制
dTruth飞机到目标真值的距离，仅用于仿真图表和捕获评价
dObs飞机到估计/预测位置的距离，控制器可见量
dAim飞机到瞄准点的距离，制导用
r, d̂飞机→瞄准点的向量与单位方向
v_t目标速度矢量，来自所选「目标位置来源」
v_t∥目标速度沿视线分量（后退为正；包络只补偿这部分）
v_t⊥目标速度垂直视线分量（绕圈/蛇形的主力）
t_go碰撞三角形解出的接触时间，夹紧 ≤ 4 s
Vmax规划速度上限（上限滑块为 0 时取 6 m/s）
k比例增益 1/s：误差 1 m → 0.6 m/s 额外接近速度
u_close沿视线的相对接近速度，按当前速度律的制动曲线或比例增益计算
R到点半径 3 m（真实距离进圈且相对速度够小才算捕获）
a_lat可用加速度（加速 a_a / 减速 a_d）
u_turn转弯约束：额外接近速度 ≤ a/λ̇ − |v_t|，λ̇ = |(v−v_t)·n⊥|/d（只削额外接近，不削前馈）
v_ref实际二维速度指令在视线方向上的投影，仅用于曲线对照
v飞机当前速度矢量（含方向滞后）
v_c沿瞄准线的接近率 = (v−v_ff)·d̂；≥0 才在缩小瞄准距离
d_brake按当前相对接近速度刹到末端速度所需距离（a_d/1.3，与包络同口径）
envelope刹车包络 v_t∥ + √(2a_d(dAim−R))，梯形律用它切减速
lag「参考点领先」：位置设定点与飞机的距离
σ_a卡尔曼过程噪声：目标加速度标准差（机载 8.0 m/s²）
Jjerk 上限（m/s³）：加速度按它爬坡，短距离时到不了 a_cap，加速度自然随场景变
