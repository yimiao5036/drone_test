## 1. 目标与原理

**目标**：消除"目标坐标（Home 基准）"与"设定值执行帧（PX4 局部帧 = EKF 锚点基准）"
之间的固定偏置 H；并顺带消除地面阶段"每次 Home 变化重置估计器"的瞬态。

**原理（一句话）**：把目标换算的基准从 Home 换成 **EKF 投影参考锚点**
（`GPS_GLOBAL_ORIGIN` #49 的 `ref_*`），使"换算基准 = 设定值执行帧的原点"——
偏置 H 不是变小，而是**定义上消失**。

**为什么是锚点**：

- 发给 PX4 的位置设定值是 `SET_POSITION_TARGET_LOCAL_NED`（`MAV_FRAME_LOCAL_NED`）的
  **局部 NED 米制量，不是经纬度**；该帧的原点就是锚点（`ref_lat/ref_lon/ref_alt`），
  PX4 内部正是用它把局部坐标换算回经纬高；
- 飞机自身位置（`local_x/y/z`）与视觉观测（自机位置 + 姿态换算）本来就在锚点系；
- 锚点 2026-10-16 实机实测稳定（`收1` 恒定、数值不变）——是唯一"天生与执行帧同源"
  的基准；Home 则随 PX4 生命周期变化（地面跟随/解锁冻结，见手册 §12.1）。

**收益**：

1. S5/S6 位置引导终点不再偏 H；
2. 视觉（锚点系）与目标估计同帧 → 创新偏差归零，**S7 交接 3m 门限不再被 H 吃掉**；
3. 估计器重置触发由"Home 变化"改为"锚点变化"（锚点不变）→ 地面阶段每 2s 重置与
   速度估计无法累积的问题一并消失。

## 3. 决策项（实施前必须定）

- **D1 锚点就绪窗口**：开机后 #49 到达前（实测约 8s，411→49 订正后由启动期一次性
  `REQUEST_MESSAGE(49)` 加速）锚点不可用。选项：
  (a) 等待锚点（期间不处理地面站目标，日志节流提示）；(b) 回退 Home 基准 + WARN
  （有 H 偏置但可用）。**建议 (a)**——开机阶段目标流本就稀少，语义更干净、不混帧。
- **D2 围栏与高度基准**：位置意图改锚点基准后，围栏钳制将变成"相对锚点原点（上电点）"。
  (a) 接受并在作业规程写明"上电点即围栏中心"；(b) 补 `home.x/y/z` 维持"相对 Home"。
  **建议 (a)**——常规流程上电点≈起飞点，两者等价，且锚点基准稳定；(b) 工作量大且
  引入新一轮基准测不准问题。
- **D3 兼容回退**：是否保留配置开关回到 Home 基准？**建议不留**——两套基准共存只会
  让排查复杂化；需要时用 git 回滚即可。

## 4. 验证计划

1. **单元/离线**：同一目标分别用锚点/Home 换算，NED 差应恰好等于 H（可用历史日志或
   构造用例断言）；
2. **SITL 回归**（锚点 ≡ 局部原点，H=0）：G3 全链行为应无变化；
3. **实机离线核对**：0040 类日志——换基准后同一目标的 NED 应平移 H（≈ 该时刻
   `局部位置`）；
4. **实机空中**（跟随开发进度测试计划 Ⓑ）：起飞后飞出 30~50m，看
   `目标估计已接受视觉观测 … 创新=` 是否稳定在噪声量级、S7 交接门限不再被吃。

## 5. 风险与回滚

- 风险：锚点流中断（`ned_ref_valid` 失效）时的行为需明确——建议"退回等待 + WARN"，
  不用 Home 静默兜底（避免混帧）；EKF 原点被重设（罕见）→ 锚点变化触发重置，语义正确。
- 回滚：改动集中在目标估计器一个模块（C1~C3），git 回退即恢复 Home 基准。
