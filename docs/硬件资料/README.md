## 注意

- 规格书文件名型号为 `23H1628889HV1`、正文型号为 `23H1328889HV1`，**不一致待厂商核实**
  （见 `docs/双目硬件事实确认记录.md` §Q1）；引用具体参数时以板上实测为准。
- 需要把这些 PDF 纳入版本管理时，删除 `.gitignore` 中 `docs/硬件资料/*.pdf` 一行并
  确认仓库体积可接受（合计约 5 MB）。
