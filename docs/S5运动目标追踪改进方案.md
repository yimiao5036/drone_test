# S5 运动目标追踪改进方案（后期）

> 状态：**待排期**（2026-10-16 立项）。
> 背景：S5（GPS 引导）把"目标当前估计位置"直接作为位置设定值发给 PX4，对静止/
> 慢速目标有效；对持续运动目标**本质是尾追**，能否跟住取决于"速度优势 + 提前量"，
> 而不由设定值刷新率决定。
> 关联：`include/state_machine/mission_state_machine.md`（S5 意图生成）、
> `include/control/flight_controller.md`「Home 漂移对控制的影响」、
> `docs/方案C锚点基准实施清单.md`（固定偏置 H，与追逐滞后叠加）、
> `include/control/tracking_control_law.md`（S7 现状）。

## 1. 问题与约束（2026-10-16 现状盘点）

现链路每环都在刷新（不是"发一次就不管"）：

```text
地面站 UPDATE(1~10Hz) → TargetEstimator Kalman（外推到当前时刻）
  → 状态机 10Hz → 位置意图（内容变化立即发 / 不变按 10Hz 上限重发）
  → FlightController 50ms → Px4Link 50ms → PX4 位置环
```

运动目标下三层滞后**叠加**：

1. **几何（尾追）**：本机速度 `v_d` > 目标速度 `v_t` 才收敛；`v_d ≈ v_t` 保持距离
   追不上（纯尾追数学必然）；`v_d < v_t` 距离发散；
2. **链路/估计**：地面站更新率与传输年龄（40~60ms）、Kalman 对机动目标的滤波滞后
   （CV 模型对加速度目标的外推误差）；
3. **执行**：PX4 位置环在**无速度前馈**时的跟随滞后（位置设定值"先落后再追"）。

另有两个叠加项：S5 引导点带固定偏置 **H**（基准差，见方案 C 清单）；追不上时的
边界行为——围栏钳制（停在边界）与目标过期停发链（COAST→IDLE）。

**后果（为什么必须管）**：S5 追不上 → 目标进不了相机视场（FOV 半角 33°/10.6°）
→ **交接不到 S7**，任务卡在接近段。S5 的追赶能力决定拦截能否开始。

## 2. 改进路径（按代价排序）

### P1 速度上限核对（零代码，先决条件）

- 核对 PX4 巡航上限（`MPC_XY_VEL_MAX` 等，含垂直通道）≥ 典型目标速度谱；
  SITL 门禁曾降到 2.0 m/s 仅为测试用，生产值须按目标速度确定；
- 交付物：一份"目标速度谱 vs 本机上限"对照（写入参数/部署文档），作为 P2~P4 的
  前提——速度不占优时任何引导律都追不上。

### P2 时间前视引导（小改动，架构不变）

- 引导点由"当前估计位置"改为 `PredictedState(t_lead)`：`t_lead ≈ 距离 / 接近速度`
  （上下限夹逼，防止外推过远），从"追当前位置"变为"瞄交汇点"；仍是位置设定值，
  PX4 照常执行；
- 改动面：状态机 S5 取点（`PublishEstimateGuidedIntent`）+ 估计器 `PredictedState`
  调用参数；**必须定义外推可信度边界**（目标机动/估计速度不可信时降级为当前位置
  引导并记 WARN）；
- 验证：SITL 注入匀速与机动目标，比较"引导点滞后/接近段距离收敛"；实机看 S5
  接近段距离是否单调收敛。

### P3 位置 + 速度前馈（中改动，需独立评审）

- PX4 `SET_POSITION_TARGET_LOCAL_NED` 支持位置与速度**同时**给（速度作前馈可基本
  消除跟随滞后）；当前实现 `type_mask` **严格二选一**、`Px4Setpoint` 无前馈字段；
- 改动面：`Px4Setpoint` 增加前馈字段 → `BuildSetpointTypeMask` 放开组合 →
  FlightController 位置通道带前馈透传（**限幅语义需重新定义**：前馈是否参与围栏
  钳制、无扰衔接如何处理）；
- 风险：涉及下行语义/限幅/日志多处，属"设定值接口扩展"，需独立评审后再动。

### P4 S7 升级为近似比例导引（长期）

- 现有 S7 = 视线角 P → `yaw_rate` + 距离 PID → `vx` + 垂直 P → `vz`（一阶伺服，
  对机动目标滞后）；升级方向：引入 LOS 角速率项（比例导引 PN），提升末端拦截精度；
- 依赖：像素视线的角速率估计质量（滤波/延迟）、双目测距可用（当前有效占比 0%，
  手册 §11.1 遗留）；
- 前提：先有 S7 实飞数据（交接成功率、末端脱靶量）再定是否需要。

## 3. 实施顺序与验收建议

P1（先决）→ P2（收益/代价比最高）→ 视目标机动性评估是否上 P3 → P4 待 S7 实飞数据。
每项统一验收方式：**SITL 注入目标脚本（匀速 / S 形 / 绕圈 / 急转）** + 实机小步验证；
观测指标：接近段距离收敛曲线、引导点滞后（估计位置 vs 本机位置）、交接成功率。

## 4. 观测方法（现状即可做）

- 机载日志已含：`目标估计已接受地面站观测 …`（含 N/E/D、VN/VE）与 `局部位置`；
  逐条算"接近速度"：若目标持续运动而接近速度趋 0 → 已落入 `v_d ≈ v_t` 区间；
- `S5 位置引导意图启动` 与后续意图内容变化可用于核对引导点滞后；
- 目标流断流/围栏钳制发生时优先排查"速度不占优"而非"刷新率不足"。
