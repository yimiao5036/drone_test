# 电源与失效保护设计

## 1. 设计原则

动力飞行安全不能依赖单一计算机。香橙派负责正常任务和正常返航，PX4保留底层飞控与算力板失效后的最后保护，遥控器保留人工接管能力。

## 2. 当前供电方案

当前硬件方案已确认：

- 无人机使用一套动力电池；
- PX4、动力系统和香橙派RK3588均由该动力电池系统供电；
- 香橙派输入要求为5V/4A，由机上稳压供电模块从动力电池转换；
- 不再使用原华为算力板所需的12V独立供电方案；
- 不设置算力板独立电池、独立BMS或`ICompanionPowerMonitor`；
- 软件中的电量、电流、剩余量和电池有效性统一读取PX4 MAVLink遥测。

供电共用不表示可以忽略稳压和瞬态问题。5V供电模块仍需覆盖RK3588、NPU、双目摄像头、网络和存储峰值负载，并验证起飞电压波动下不会导致香橙派重启。

## 3. 电池数据来源

唯一软件电池来源：

```text
动力电池
→ PX4电源模块/ADC
→ SYS_STATUS / BATTERY_STATUS
→ Px4Link::FlightStateSnapshot
→ 状态机 / HealthManager / GroundStationLink
→ Web地面站
```

使用字段包括：

- `battery_valid`与总电压；
- `battery_current_valid`与电流；
- `battery_remaining_valid`与剩余百分比；
- 对应消息接收时间和新鲜度。

不得把无效电池字段伪造为0，也不得在PX4电池数据超时后继续按旧电量进行任务决策。

## 4. 上电和起飞检查

起飞前至少检查：

- PX4动力电池状态有效并满足配置门限；
- PX4 GPS/位置、姿态、航向和Home有效；
- 遥控器链路和接管开关状态符合起飞条件；
- 香橙派与PX4串口稳定；
- 双目摄像头、解码、YOLO及任务所需感知能力正常；
- 香橙派未发生欠压、重启或系统级异常。

任一飞行安全必需能力失败时，不得由香橙派请求解锁。

## 5. 正常返航与后备RTL

### 5.1 正常返航

- V1拦截结束后默认返回；
- 香橙派使用PX4上报的Home点，不自行记录独立GPS；
- 香橙派持续生成位置或速度设定值，控制无人机返回Home；
- 双目视觉和光流继续运行；
- 当前避障策略只允许减速、刹停和悬停，不自动绕行。

### 5.2 后备RTL

以下情况由PX4执行最终保护：

- 香橙派死机、重启或断电；
- 5V稳压供电异常导致算力板掉电；
- 控制进程崩溃或卡死；
- 香橙派与PX4串口中断；
- Offboard设定值停止或失效。

PX4 1.17.0 SITL已实测：`COM_OF_LOSS_T=1.0s`、`COM_OBL_RC_ACT=0`；仅停止setpoint、保持HEARTBEAT时，应用约1270ms后观测到模式从Offboard 6/0切换到AUTO/RTL 4/5。真实Pixhawk仍需在拆桨台架复核参数、触发时间和实际动作。

## 6. 控制权和遥控器

```text
PX4内部安全保护
  > 遥控器人工接管
  > 香橙派安全控制
  > 香橙派正常任务控制
  > 地面站任务指令
```

- 遥控器用于测试、故障处置和人工接管；
- 接管触发后，香橙派停止正常任务输出；
- 人工控制期间仍可记录和回传健康状态；
- 恢复自动控制必须经过明确操作，并重新检查模式、位置、Home、目标、双目深度和电池状态。

## 7. 失效矩阵

| 故障 | 香橙派还能工作 | 当前处置 |
|------|----------------|----------|
| 地面站目标过期 | 是 | 停止使用旧目标；按任务阶段搜索、悬停或返回 |
| 地面站链路断开 | 是 | 上报告警；按配置保持、继续安全动作或返回 |
| 双目摄像头/图像失效 | 是 | 禁止视觉接管和深度测距；跟踪阶段退出正常视觉控制 |
| 双目深度无效 | 是 | 禁止依赖绝对距离，降低速度并保守处置 |
| PX4动力电池低 | 是 | 阻止新任务，取消继续拦截并返航或安全降落 |
| PX4电池数据超时 | 是 | 电量状态按未知处理，禁止依赖旧值继续任务 |
| PX4串口中断 | 部分 | 香橙派无法控制；PX4执行自身保护 |
| 5V稳压输出异常 | 可能否 | 香橙派可能重启/断电，PX4执行自身保护 |
| 控制进程卡死 | 否 | PX4根据设定值丢失执行自身保护 |
| 香橙派断电/重启 | 否 | PX4执行自身保护，香橙派重启后不得恢复旧控制状态 |
| 遥控器接管 | 是 | 进入人工控制，停止正常任务输出 |
| 返航遇障碍 | 是 | 刹停悬停，等待人工处置或危险解除 |

## 8. 香橙派重启规则

香橙派启动时一律进入`BOOT/SELF_CHECK`，即使检测到无人机已经在空中，也不得根据本地持久化状态直接恢复之前的速度或位置控制。

空中重启后的允许行为需要单独设计。V1应以读取PX4当前状态、保持不冲突和请求人工处置为原则，不能自动重新解锁或重复执行拦截动作。

## 9. 看门狗与运行监控

后续实现应包含：

- 控制循环心跳和最大延迟；
- PX4设定值发送连续性；
- 线程存活、队列积压和内存池耗尽；
- 系统温度、整机CPU负载、NPU状态和推理延迟；
- Linux欠压/重启原因与系统日志诊断；
- 硬件或系统级看门狗可行性；
- 最后任务状态持久化仅用于诊断，不用于自动恢复控制。

## 10. 电源硬件验证

虽然软件不设置独立电源管理模块，仍必须完成以下台架验证：

1. 测量动力电池最高/最低电压下5V稳压模块输出；
2. 验证5V/4A持续能力和瞬态余量；
3. 视频解码、YOLO、编码推流和双目深度同时运行时测量峰值电流；
4. 起飞、电机快速变速和低电量场景观察香橙派是否欠压或重启；
5. 拔断香橙派供电，确认PX4后备保护不依赖香橙派继续工作；
6. PX4电池消息失效/超时测试必须触发未知或降级，不能保留旧电量。

## 11. 待定项

- 5V稳压模块型号、持续/峰值电流、效率和散热；
- PX4动力电池起飞、返航和临界门限；
- 遥控器接管开关、恢复流程和失联动作；
- PX4 1.17.0数据链丢失、RC接管/失联和真实硬件RTL参数清单；
- Home高度基准、返航高度和降落策略；
- 地面站断联后的最终任务策略。
