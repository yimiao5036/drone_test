## 3. 逐层形态

符号定义见演示页顶栏「符号表」；下面只给"输入 → 计算 → 输出"。

### 3.1 估计与时延补偿

- 位置进卡尔曼（过程噪声 `σ_a`，机载 8.0 m/s²）；显式速度位**只做前馈，不喂滤波器**。
- 量测年龄 `elapsed = t_now − t_measurement`（含链路时延，实测 0.2~0.4 s）。
- **时延补偿点** = 滤波状态 + 滤波/显式速度 × `elapsed`。它把"过期量测"推到"现在"，**不含任何提前量**。

### 3.2 提前量与瞄准点

```text
lead_m = 额外提前量(m) + (距离自适应 ? min(0.06·(dObs − R), 2 m) : 0)
lead_s = lead_m / max(0.5, |v_t|)
瞄准点 a = 时延补偿点 + v_t·lead_s      （速度匹配模式 t_go = 0）
```

- **距离自适应**是默认口径（2026-11-11 拍板）：远了给大提前量避开迎面横穿，近了收小避免冲过头。它是"安全间距 ↔ 末端速度"的折中，**不是"追不上"的解药**（实测见分析文档 §5.23）。
- 画布上区分两条线：**制导线**（设计机→瞄准点，控制器真正追的方向）与**视线**（设计机→真值目标，只用于距离读数与评价）。
- 链路时延补偿**恒定且必须保留**：缩掉它等于瞄准目标 0.3 s 前的位置，会留下米级结构性滞后。

### 3.3 接近速度预算

```text
u ≤ √(V_body² − v_t⊥²) − v_t∥        （V_body = 速度上限，滑块 0 → 规划 6 m/s）
v_des = v_t + u_close·d̂
```

- 目标沿视线后退 `v_t∥` 吃掉的是**速度余量**；`V_body ≤ v_t∥` 时接近预算 ≤ 0 —— 这是"追不上"的物理含义，与目标速度的绝对值无关。
- 这也是"零余量对照机"（红）的定义：它的 `V_body` 恒等于 `|v_t|` → 稳态接近速率 ≡ 0。

### 3.4 制动包络

```text
a_d_eff = min(a_d(s), a_term_eff) / 1.3        （1.3 = BRAKE_SAFETY）
u_close = brakingSpeed(dObs − R, a_rad, a_d_eff, J, cap, dt)
末端 dObs < R−0.1 时改用有符号比例反馈 close = −min(1.5·(R−0.1−dObs), brakingSpeed(...))
```

- 用**控制器可见的估计距离** `dObs`，不用瞄准点距离 `dAim`（后者会比目标多 `v_t·t_go`，把可用刹车距离算虚）。
- `dObs − R` 用控制间距 `R − 0.1 = 2.9 m`；**3 m 是到点告警半径，不是防撞禁入区**。
- `J > 0` 时制动距离按分段积分计入加速度回收；`J = 0` 时为 `u²/(2a)`。
- 离散化必然越界，所以减速度先除以 1.3；实测默认工况最小距离 2.90 m。

### 3.5 动态侧向预算与转弯约束

```text
a_side = â_t⊥ + u·λ̇                         （目标法向机动 + 跟住视线旋转所需）
a_rad  = √max(0, a_eff² − a_side²)           （加速度圆里先扣侧向，剩下才给径向）
相对加速上限 = max(0, a_rad↑ − â_t∥)
相对减速预算 = max(0, a_rad↓ + â_t∥)          （不透支"目标继续向外加速"的收益）
转弯约束：u_extra ≤ max(0, 0.8·min(a_eff↑,a_eff↓) − |â_t⊥|) / |λ̇|，λ̇≈0 时不约束
```

- `â_t` 只在收到新速度样本时差分并低通，**不读真值**。
- 转弯约束**只削额外接近速度，不削目标速度前馈**——否则高速绕圈会"追得上但匹配不了"。

### 3.6 急停预留（可选）

目标最大内向加速度界 `B > 0` 时，按 `a_target∥ ≥ −B` 收紧制动预算，并计入"采样 + 传输 + 一拍"的反应距离。`0.5 m` 只是该一维模型的几何余量，**不能当作任意二维机动的安全证明**。

### 3.7 加速度调度（分相位，固定开启）

```text
need     = max(|â_t|, needHold)                     # needHold = 目标机动需求的单调峰值保持
a_term_eff = max(a_term, need + 0.5)                # 近段下限，不因目标过零而回退
w        = clamp((dObs − 8) / 4, 0, 1)，变化率 ≤ 0.8/s   # 8~12 m 过渡带
a_plan(s) = a_term_eff + (a_plan − a_term_eff)·w
a_eff    = min(a_plan(s), a_phys, √(a_phys² − a_lat²), slew_eff)
```

- **为什么近段要抬下限**：加速度圆里径向与侧向共用一份预算；`a_term` 低于目标机动需求时，`relativeBudget` 会把沿视线加速预算算成 0（实测蛇形 7.2 m/s：需求 3.80 而 `a_term` 1.5 → 越追越远、退到 12.31 m）。
- **为什么用峰值保持**：蛇形横向加速度是正弦，瞬时过零就把上限放回去会让飞机反复松手（实测到点 38.8 s vs 固定 22.2 s）。
- **为什么要变速**：8~12 m 带内目标机动会让 `w` 每拍抖动，上限跟着抖动（实测 1.2 次/秒），命令随之抖。
- 包络侧的 `a_d(s)` 与 `a_term_eff` 同源，否则远段按 3 规划、近段才收紧会刹不住（历史 bug：minD 0.11 m）。

### 3.8 指令限幅

```text
slew_eff = P.slew > 0 ? max(P.slew, 提能力生效时的规划值) : ∞
指令变化率：一次/二阶限幅（slew = 加速度上限；J = 加速度变化率上限）
硬速度上限优先：超出 V_body 时直接裁剪并计数（此时不保证 jerk）
```

- **`slew` 是"下发力"约束，`a_plan` 是"规划值"**：`a_plan > slew` 时只剩 `slew` 起作用（这正是"a_plan 拖到 5 却没有变化"的原因）。
- `J > 0` 让指令加速度连续（像真机的姿态/速度环）；它不是安全参数——实测小 J（2）反而让末端贴得更近（minD 2.90 → 1.31 m）。

### 3.9 垂直通道

与水平解耦：`vz_des = vz_match + sign(dz)·min(VZ_MAX, √(2·(AZ_MAX/1.3)·max(0,|dz|−0.2)))`，限速 2 m/s、限加速 2 m/s²。`|dz| ≤ 2 m` 是到点判据的一部分。

### 3.10 页面里的三个对照体

| 体 | 上限 | 律 | 用途 |
|---|---|---|---|
| 蓝（设计） | `min(a_plan(s), a_phys, …, slew_eff)`；`V_body` | 制动曲线 + 速度匹配 | 本文算法 |
| 红（零余量） | `V = |v_t|` | 同上 | 证明"余量 = 稳态收敛速率"，按定义永不收敛 |
| 绿（纯比例尾追） | `V_body` 用满 | `u = k(dAim−R)`，k=0.6 固定 | 证明"纯尾追能到点，但没有梯形剖面/制动余量" |

## 5. 状态与判据

| 判据 | 阈值 | 说明 |
|---|---|---|
| 到点告警 | 水平 ≤3 m、垂直 ≤2 m、速度 ≤0.5 m/s（相对或地速），**连续保持 2 s** | 与 `handover.arrival_*` 对齐；只是告警线 |
| 视觉交接（示意） | LOCKED 连续 10 帧 + 斜距 ≤7.95 m + 俯仰 ≤5.24° + 创新 ≤3 m | 与 `handover.lock_frames / fow_margin_deg / innovation_gate_m` 同构；机载交接还看真实检测与测距 |
| **穿透 / 撞击** | `d < 0.5 m` → **粘性失败标记** + 次数统计；判词首条报"判定为撞击（失败）" | 演示无碰撞模型，用此替代；真机上 0.5 m 以内即已撞 |
| 停滞 | 4 s 内没有 ≥1 m 实质进展且未到点 | 擦身而过不算进展；顶栏变橙 |
| 能力受限 | 相对径向预算 ≤0 或 上/下预算 ≤0 | 判词"当前匹配或制动预算不足" |
| 制动不可行 | `decelEff < 0.05` | 读数显示"不可行(预算≈0)"，且**不画**刹车示意圆 |

## 6. 已知边界与未建模

- **无 PX4 内环**：演示是"速度指令 + 加速度限幅"的运动学模型；真实位置/速度环滞后与饱和见分析文档 §2.3。
- **无视觉检测/遮挡**：交接是理想朝向/检测下的几何示意，位置 KF 创新不等于真实视觉创新。
- **无碰撞模型，也不建模目标横向扫过来**：1D 刹车包络 + 加速度圆不等于任意二维机动的安全证明。
- **估计有滞后**：突发机动、链路丢包时包络会被撑破（最差链路实测穿球到 0.036 m）。
- 制动距离用了 `max(1e-6, decel)`，减速度预算→0 时会算出 1e7 m 量级；已用"不可行"标记 + 绘制上限挡住，但**没有把它变成物理量**。

## 7. 与机载实现的差异（2026-11-11 已落机载）

机载 S5 自 2026-11-11 起按本文速度律运行（实现见
[`../include/control/approach_speed_law.md`](../include/control/approach_speed_law.md)）：

| 项 | 本文（演示页） | 机载 S5（2026-11-11 起） |
|---|---|---|
| 下发内容 | 二维速度指令 `v_des`（+ 加速度限幅） | 速度锚点 `p_ref = 自机 + v_ref × 0.3s` + 速度前馈 `v_ref`（同一律产出；2026-11-11 SITL 起不再用目标前 standoff 点） |
| 提前量 | 距离自适应（0~2 m）+ 额外提前量 | 同（时延补偿 + 距离自适应；额外默认 0） |
| 引导点平滑 | 瞄准点 + 插值渲染 | 速度指令 `slew` 限幅；位置点与速度同源 |
| 速度上限 | `V_body` + 二维修正 `√(V²−v_t⊥²)−v_t∥` | `controller.max_speed_mps=10`（唯一来源，注入速度律）+ 控制器前馈/引导硬上限 |
| 制动包络 | 有 | 有（含一拍反应距离与 `brake_safety=1.3`） |
| 加速度调度 / 末端 / 穿透 / 提能力 | 有 | 有；穿透只作诊断，不作失败判据 |
| 到点/交接判据 | 同 `handover.*`（3 m / 2 m / 0.5 / 2 s / 10 帧 / 5° / 3 m） | 一致 |
| 未移植 | — | jerk 二阶平滑、`end=stop` 碰撞三角形、UI/评价量 |

落地形态：**目标形态**——S5 每拍产出 `(p_ref, v_ref)`，`p_ref` 是“自机 +
v_ref × 0.3s”的速度锚点，位置只作 PX4 的兜底锚点；旧“目标点 + 固定提前 +
低通”实现已于 2026-11-11 删除，不保留回退开关。
