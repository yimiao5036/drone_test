# 感知与避障设计

## 1. 设计范围

当前单目前视摄像头准备更换为双目摄像头，计划使用左右同步图像进行目标识别、光流和深度测距；独立单点激光雷达方案取消。本文定义数据关系、能力边界和策略接口，不承诺在双目硬件、标定和有效距离验证前实现完整三维绕障。

## 2. 传感器配置

### 双目摄像头

- 计划固定安装并指向机头正前方。
- 左右相机必须具备可验证的时间同步或硬件同步能力。
- 码流是双路独立视频、拼接视频还是厂商深度输出，目前待新摄像头资料确认。
- 分辨率、帧率、基线、视场角、SDK、深度格式和RK3588支持情况均需上板确认。
- 双目深度不得与YOLO框直接默认关联，必须在校正后图像和对应时间戳上计算目标区域有效深度。
- 当前`CameraReceiver`单路RTSP接口保留，待硬件协议确认后再决定扩展双路Topic或新增双目适配器。

### 光流

- 没有独立光流传感器。
- 算力板根据解码后的相邻视频帧计算。
- 光流是运动信息，不等同于绝对距离。
- 必须输出质量指标，在低纹理、强压缩、模糊和光照异常时允许失效。

### 独立激光雷达

当前产品不接入独立单点激光雷达。已有`ILaserRangeFinder`、`LaserRangeSample`及相关位定义仅作为兼容预留，不进入正式主程序装配、不参与健康门禁，也不在Web页面显示。未来若双目有效距离不足并重新评审雷达方案，必须由维护者确认后再启用。

## 3. 标定与时间对齐

实现视觉控制前必须完成：

- 左右相机各自内参和畸变标定。
- 双目旋转/平移外参、基线和立体校正参数。
- 双目相机坐标系到机体坐标系的固定外参。
- 左右图、检测、光流、深度和PX4姿态的时间对齐。

视觉像素只有结合相机模型和对应时刻的机体姿态，才能转换为目标相对机体的视线方向。

双目深度只有在左右图同步、立体匹配质量有效、目标区域有足够有效视差且时间与检测结果对齐时，才可与目标关联。无效像素、低纹理、反光、远距离或遮挡场景必须输出距离无效，不能回退为0。

## 4. 感知流水线

```text
双目摄像头左右同步图像
  -> 双路接收/解码与立体校正
  -> 图像质量和同步检查
  -> YOLO 检测 ----------------------┐
  -> 相邻帧光流 --------------------┼-> 感知融合
  -> 双目视差/深度 -----------------┤
PX4 姿态、航向、速度 ---------------┘
                                      -> 目标状态 / 障碍状态
```

YOLO V1 输出：

- 类别。
- 置信度。
- 像素检测框和中心位置。
- 对应图像序号与时间。

类别至少预留“无人机目标”和“障碍物”。障碍物具体类别和是否增加图像分割尚未确定。

## 5. 目标跟踪

### 稳定锁定

单帧检测不能立即接管飞行控制。稳定锁定至少考虑：

- 连续检测次数。
- 置信度。
- 检测框位置连续性。
- 光流运动一致性。
- 数据年龄。
- 多目标时的目标编号一致性。

具体阈值通过录制数据和实飞测试确定。

### 卡尔曼滤波

状态估计器可采用卡尔曼滤波或其他可替换实现，用于：

- 平滑像素位置和相对运动。
- 融合不同时刻的目标状态。
- 处理短时间漏检。
- 为搜索方向提供有限时预测。

卡尔曼滤波不能判断目标是否被击落、离开、遮挡或被错误分类。预测超过时间或不确定度上限后必须停止作为正常跟踪依据。

### 视觉丢失

`ITargetLostStrategy` 的 V1 候选流程为：

1. 短时使用状态估计器预测，并限制控制速度。
2. 读取最新有效的地面站目标状态。
3. 若 GPS 目标仍在附近，则悬停或低速转动整机搜索。
4. 若目标位置已经明显移动，则退出视觉控制并回到 GPS 位置引导。
5. 若地面站目标也无效，则停止追踪并进入保守处置。

搜索时间、扫描角度、GPS“附近”判定和最终退出动作仍待定。未来有云台时，只替换搜索执行器和相机姿态提供器。

## 6. 位置到视觉控制切换

视觉接管不使用固定距离阈值，而由稳定锁定触发。切换前还必须满足：

- 已进入上一位置设定值的误差范围。
- 本机速度低于配置阈值。
- 视觉数据和 PX4 姿态新鲜。
- 前向没有危险。
- 视觉控制器已经生成通过限幅的首条速度指令。

不要求坐标完全相等。“直接切换”表示不增加额外飞行模式阶段，但仍需保证控制输出连续和有效。

## 7. V1 障碍处理

### 输入职责

| 输入 | V1 职责 |
|------|---------|
| YOLO 障碍物结果 | 判断画面中存在障碍及其大致方位 |
| 光流 | 判断图像运动和接近趋势，提供辅助质量信息 |
| 双目深度 | 提供目标区域和前向障碍距离及质量；硬件/算法未定型前不得用于实飞门禁 |
| PX4 状态 | 提供本机速度、姿态和航向 |

### 安全停止策略

V1 的 `IObstacleAvoidanceStrategy` 实现为 `StopAndHoldStrategy`：

```text
无危险
  -> 保持当前任务控制

进入减速区
  -> 限制前向速度和加速度

进入制动区或碰撞风险过高
  -> 刹停
  -> 悬停
  -> 上报地面站

危险解除
  -> 重新确认雷达、视觉、任务输入和控制状态
  -> 再决定恢复原任务
```

阈值应考虑当前速度和制动距离，不能只有一个固定距离开关。双目深度无效、视觉质量过低或多源结果明显矛盾时，采取保守动作并上报告警。

### V1 不提供的能力

- 不自动证明左、右、上、下通道安全。
- 不自动生成绕障路径。
- 不依赖单目图像给出未经验证的绝对深度。
- 不在障碍状态下盲目恢复原速度。

返航时使用同一避障接口。V1 返航遇障碍后悬停，等待遥控器接管、地面站处置或危险解除。

## 8. 后续避障升级

状态机只依赖 `IObstacleAvoidanceStrategy` 的通用输出：

- 当前风险等级。
- 允许的速度约束。
- 建议控制动作。
- 是否需要进入悬停。
- 是否允许恢复任务。
- 决策置信度和原因。

后续可以增加：

- 障碍物分割和可通行区域检测。
- 双目深度算法、目标区域稳健统计和置信度估计。
- 在双目能力实测不足时重新评审多方向测距、扫描雷达或2D/3D激光雷达。
- 局部占据栅格。
- 动态窗口、采样规划或其他局部规划算法。

升级算法不得绕过速度限制、控制权仲裁和 PX4 最终保护。

## 9. 降级原则

| 故障 | GPS 接近 | 视觉跟踪 | 返航 |
|------|----------|----------|------|
| 摄像头失效 | 可继续位置引导，禁止视觉接管 | 退出视觉跟踪 | V1 失去视觉障碍识别，保守处置 |
| 光流失效 | 可降级 | 降低跟踪可信度和速度 | 可降级但告警 |
| 雷达失效 | 禁止依赖绝对前向距离 | 降低速度或退出近距操作 | 保守悬停或人工接管 |
| 地面站目标过期 | 停止更新位置目标 | 可按策略短时视觉跟踪 | 不影响已开始的 Home 返回 |
| PX4 姿态过期 | 禁止空间转换和控制 | 立即退出正常控制 | 交由安全保护 |

具体降级动作由任务阶段、速度和环境共同决定，表中规则还需仿真和实机确认。
