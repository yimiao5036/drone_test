# 阶段四正式控制接入路径设计（冻结稿）

> 创建日期：2026-10-13
> 状态：设计冻结待实现（实现前需维护者审阅本稿）
> 上游文档：`docs/主程序集成与数据链路实施计划.md` §4.4、`docs/物理追踪思路.md` §7/§8/§9、
> `docs/状态机设计.md`（S5/S6/S7 骨架）、`docs/系统架构设计.md` §8
> 安全基线：本设计落地前 `runtime.enable_control=false` 不变；任何实现 PR 不得单独打开。

## 0. 范围与已确认决策

本次设计覆盖**全链接入路径**：GPS_APPROACH 位置引导链 + VISUAL_TRACKING 视觉末段链 +
交接缝（S5↔S6↔S7）+ 控制权门禁 + SITL/台架验收分级 + `enable_control` 打开条件。

维护者已确认的选型（2026-10-13）：

1. **范围**：全链一次冻结，交接缝详细设计一并完成，不留二期返工；
2. **架构**：方案 A——单层 `FlightController`，仲裁/交接判据留在状态机，
   执行层职责（限幅/无扰/新鲜度/门禁）归 `FlightController`；
3. **人工接管**：PX4 模式切换为主——飞手拨杆切非 Offboard 模式即原生生效，
   机载侧检测到模式离开 Offboard 立即停发 setpoint 加速退出，机载不做 RC 通道值解析判定。

## 1. 组件架构与数据流

```text
地面站目标 ──→ MissionStateMachine（正式化：去影子）
                    │  订阅：TargetEstimator.TargetState（热备份卡尔曼）
                    │        VisualTargetMonitor.Status（LOCKED/LOST）
                    │        StereoRanger.Distance、FlightState、HealthStatus
                    │  产出：ControlIntent（control_source=0 位置 / 1 视觉 / 2 安全）
                    ▼
            FlightController（新真实实现，固定周期线程）
                    │  职责：限幅（v/a/jerk）、无扰切换、新鲜度监控、
                    │        刹停/悬停、控制权门禁
                    ▼  Px4Setpoint（kPx4Setpoint）
            Px4Link.SetInput() ← 仅在 enable_control=true 时绑定
                    │
                    ├─ SET_POSITION_TARGET_LOCAL_NED（Offboard 速度/位置流）
                    ├─ 命令白名单扩展：MAV_CMD_DO_SET_MODE(176)、ARM(400)、
                    │   DO_SET_ACTUATOR(187，捕网)——执行器命令同属控制输出门禁
                    ▼
                  PX4（Offboard；人工拨杆切模式即原生退出）
```

接线决策：

1. `enable_control=false` 时 `DroneApplication` 不执行 `px4_link->SetInput()`，
   FlightController 可影子运行（发布 setpoint 到 Topic 供观察，无消费者）；
2. `VisualTrackingShadow` 退役为状态机内部数据源：正式化后视觉伺服意图由状态机在
   S7 发出（`control_source=1`），控制律计算沿用已验证的 `tracking_control_law`，
   调用点移入状态机（或其内部协作者）——同一时刻只有一个意图生产者；
3. FlightController 固定周期线程（`controller.period_ms`，初值 50ms/20Hz；
   Px4Link 侧已有 20Hz 重发与 500ms 硬超时兜底）；
4. 捕网机构走 `Px4Link::SendCommand(MAV_CMD_DO_SET_ACTUATOR)`，复用现有 ACK 设施，
   由状态机在拦截状态触发，同受 `enable_control` 门禁；
5. `IFlightController` 接口签名不变（`SetInput(ControlIntent)`/`SetpointOutput()`），
   Stub 保留供骨架测试。

## 2. 交接缝详细设计（S5 ↔ S6 ↔ S7）

所有阈值进 `config.json` 的 `handover` 节，不落代码字面量。

### 2.1 进入判据（S5→S6，全部同时满足，迟滞计数）

| 条件 | 判据 | 配置项（初值待定） |
|---|---|---|
| 视觉锁定持续 | `VisualTargetStatus.state=LOCKED` 连续 N 帧（非累计） | `handover.lock_frames` |
| 双目距离有效 | `StereoTargetDistance.valid` 且未超龄 | 复用测距 `valid_for_ms` |
| 视线角余量 | 目标视线角距视场边缘 ≥ α°（防交接即丢目标） | `handover.fow_margin_deg` |
| 创新一致性 | 视觉 NED 观测与卡尔曼预测的水平距离 < γ m（防错锁伪目标） | `handover.innovation_gate_m` |

任一失效保持 S5；进入 S6 后冻结最后位置目标。

### 2.2 S6 交接验证

- 位置误差 < ε、地速 < v_max、首条视觉指令经限幅后有效 → S7；
- 任一切换条件失效 → 撤销回 S5；
- **S6 驻留超时**（`handover.timeout_ms`）→ 回 S5，防卡死。

### 2.3 退出迟滞（S7→回退）

- 视觉 LOST 连续 M 帧（`handover.exit_lost_frames`）或距离失效超 T ms 才退；
- 配置校验强制 `exit_lost_frames > lock_frames`，否则拒绝启动（fail-fast）。

### 2.4 热备份

视觉融合在地面站有效期内常驻更新卡尔曼（2026-10-12 已落地）；验收项：S7 期间
每秒核对卡尔曼状态年龄 < 阈值，断粮立即节流 WARN（防"假备份"）。

### 2.5 无扰切换（FlightController 执行层职责）

- S5→S6：位置式→速度式切换时，首条速度指令以当前实测速度为起点斜坡过渡
  （slew-rate 限制），禁阶跃；
- S7 视觉丢失瞬间：图像空间 coast——沿用控制律现有 `coast` 机制短时保持/
  斜坡衰减输出（像素级预测顶几帧），不立刻跳回世界系环；
- 回退 GPS 链时同样斜坡衔接。

### 2.6 世界系只做前馈

卡尔曼航迹按已知死时间（测距 ≈40ms + 姿态链路，标量配置）外推后作为视觉伺服的
lead 提前量；**不进内环反馈路径**（`物理追踪思路.md` §7.1 延迟归因结论）。

## 3. FlightController 执行层

**运行模型**：固定周期线程，每周期：

```text
取最新 ControlIntent 快照
  → 门禁链（按序，任一不过走降级出口）：
    ① 意图超龄？（StalenessChecker，valid_until_ms）
    ② 控制权有效？（连接、Offboard 模式确认、无人工接管迹象）
    ③ 目标值有限性（NaN/Inf 拒绝）
  → 限幅流水线：速度幅值限幅 → SlewRateLimiter 加速度限幅
    →（jerk 限幅 v1 预留配置位，可先只配 v/a 两级）
  → 无扰衔接：意图 control_source/类型变化时，斜坡起点=上一周期实际输出
  → 发布 Px4Setpoint（NED 速度式为主；位置式仅用于 S5 远端引导）
```

复用已测构件：`SlewRateLimiter`（初值 0 天然实现首条指令突变抑制，S6 要求）、
`StalenessChecker`、`PidController`。

**降级出口**（优先级从高到低）：

| 触发 | 出口行为 |
|---|---|
| 控制权失效（心跳断/非 Offboard/人工接管） | 立即停发（`valid=false`），PX4 原生失控保护接管（SITL 3D 已验证） |
| 意图超龄/丢失（短期 < `coast_timeout_ms`） | 零速刹车（有效零速度指令） |
| 意图长期无恢复 | 停发，交还状态机决策（LOST/返航语义） |

**边界**：不读 PX4 原始遥测做决策（只从 Px4Link 状态接口读连接/模式做门禁，
不订阅 Topic 避免环路）；不做坐标转换/目标估计/RC 通道解析；输出类型映射
`ControlIntent.type` → `Px4Setpoint`，`use_yaw/yaw_rate` 互斥校验沿用现有约束；
全部参数进 `controller` 配置节并 `Validate()` 关系校验。

## 4. 控制权与安全门禁

**授权链（五道门，全部通过才产生控制输出，任一断开即撤）**：

```text
config: enable_control=true（人工显式打开，默认 false，永不入库）
  → ① 部署门禁：装配期校验 FlightController 真实实现存在且配置 Validate 通过
  → ② 链路门禁：PX4 心跳连接 + 固件版本核验一致（已有设施）
  → ③ 健康门禁：HealthStatus 关键位全绿
  → ④ 控制权门禁：确认 PX4 处于 Offboard 且 armed（每周期核验，非一次性）
  → ⑤ 意图门禁：ControlIntent 未超龄且字段合法
```

**控制权状态（FlightController 内部三态）**：

| 状态 | 含义 | 迁移 |
|---|---|---|
| `IDLE` | 无控制权，停发 setpoint | 授权链全通且状态机显式请求 → `ACTIVE` |
| `ACTIVE` | Offboard 控制中 | 任一门禁失效 → `IDLE` |
| `COAST` | 意图短期超龄的刹车保持 | 恢复 → `ACTIVE`；超时 → `IDLE` |

**人工接管**：拨杆切非 Offboard → PX4 原生忽略 setpoint；机载每周期核验
`flight_mode`，离开 Offboard 立即停发 + 转 IDLE + WARN（目标 < 200ms）；
RC 信号丢失不作为接管触发（PX4 失控保护链已覆盖，SITL 3D 验证）。

**飞行围栏（输出侧硬限，配置化）**：最大速度、最大高度（相对 Home）、
最大水平半径（相对 Home）；越界意图钳制 + 节流 WARN；参数实飞前按场地冻结。

**命令通道扩展**：`DO_SET_MODE(176)`/`ARM_DISARM(400)`/`DO_SET_ACTUATOR(187)`
加入白名单但仅状态机可调——窄接口 `IPx4CommandSender`（仅 `SendCommand` + ACK
查询）注入状态机，`enable_control=false` 时不注入（装配期物理隔离）。
ARM/模式时序沿用 SITL 3A 纪律：先发 Offboard setpoint 流 → 模式 ACK 且真实
模式=6/0 → 才允许 ARM。

**安全红线**：任何情况下不伪造 PX4 Home/姿态绕过门禁；`enable_control=false` 时
不绑定 `SetpointOutput`、不注入命令接口（现有静态搜索核查继续有效）。

## 5. SITL / 台架验收分级

沿用 `px4_link_smoke` 分级模式扩展第 4 系列（`--sitl-stage4-*` 参数族，
强制 UDP 门禁，串口配置拒绝 stage4）；每级不过不进下一级，失败回修复不降级通过。

| 门禁 | 环境 | 内容 | 通过标准 |
|---|---|---|---|
| G0 | WSL2 单测 | 限幅流水线、无扰衔接、门禁链、coast 刹车、交接判据迟滞、围栏钳制 | 新增用例全绿 + 既有基线不回归 |
| G1 | SITL 回归 | 现有第 0~3D 原样复跑 | 全部通过 |
| G2 | SITL 执行层 | `enable_control=true` + 仿真：零速度保持、阶跃响应（slew 无突变）、围栏钳制、意图超龄→刹车→停发、飞行中切非 Offboard→立即停发 | 位移/速度包线符合限幅；超龄刹车 < 1 控制周期 + 500ms 硬超时内；模式切换停发 < 200ms |
| G3 | SITL 全链 | 状态机转正：注入地面站目标 + 模拟视觉观测走通 S5→S6→S7→回退→返航；视觉丢失注入验证 coast 与热备份回退 | 迁移序列与 §2 判据一致；交接处输出连续；回退后卡尔曼备份接管有效 |
| G4 | 拆桨台架 | 真实 PX4 + 机体（卸桨）：ARM/Offboard 流程、电机输出方向、捕网 PWM 行程/方向（DO_SET_ACTUATOR）、断链失控保护 | 电机仅怠速级响应且方向正确；捕网到位；断链 → 停发/上锁符合预期 |
| G5 | 室外首飞 | 系留/低空低速人工兜底（另立清单，超出本设计） | 另行冻结 |

**失败处置纪律**：G2 起任一级出现非预期位移、非预期 armed、PX4 failsafe 触发，
按缺陷处理（systematic-debugging），禁止调参掩盖。

## 6. `enable_control` 打开条件与配置

**打开前置清单（缺一不可）**：

| # | 条件 | 证据 |
|---|---|---|
| 1 | G0~G4 全部通过 | 验收记录回填 `docs/开发进度.md` |
| 2 | 双目测距卷尺级精度验收 + fxB 绝对精度对齐 | 独立测试工程结论回填 |
| 3 | 控制律参数整定完成（非占位值） | SITL/回放整定记录 |
| 4 | 相机安装外参标定（消除全 0 准直假设） | 标定参数入库 |
| 5 | 围栏参数按试飞场地冻结 | `config.json` 评审 |
| 6 | 室外实链只读验证通过（状态机越自检、NED 影子正常） | `PX4实链验证清单.md` §6 回填 |

**配置结构**（新增节，全部 Validate 关系校验）：

```json
"runtime": { "enable_control": false },
"controller": {
  "period_ms": 50,
  "max_speed_mps": 0, "max_accel_mps2": 0, "max_jerk_mps3": 0,
  "max_altitude_m": 0, "max_radius_m": 0,
  "intent_timeout_ms": 0, "coast_timeout_ms": 0,
  "slew_transition_ms": 0
},
"handover": {
  "lock_frames": 0, "fow_margin_deg": 0, "innovation_gate_m": 0,
  "timeout_ms": 0, "exit_lost_frames": 0
}
```

（数值 0 为占位，实现时按整定结果填初值。）

**运行时显性标记**：`enable_control=true` 启动打 **WARN** `正式控制输出已启用`；
FlightController 进出 `ACTIVE` 打状态变化日志；MissionStatus 下行 `control_source`
字段 Web 端可见。

**回滚通道**：现场改回 `enable_control=false` 重启即回纯影子；配置误开但前置
未满足时装配期 fail-fast 拒绝启动，不静默降级。

**提交纪律**：`enable_control=true` 的 `config.json` 永不入库——仓库生产配置永远
false，打开只发生在现场部署目录本地副本（写入 `docs/部署与打包.md`）。
