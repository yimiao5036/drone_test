# 相机内参标定工具设计（Windows 离线，ChArUco，双目+立体外参）

> 日期：2026-09-22 ｜ 状态：已评审冻结
> 范围：USB 双目模组（23H1328889HV1）在 Windows 电脑上的离线标定工具；
> 产出左右目内参/畸变 + 立体外参 R/T 的标定文件，对接 `visual_track_control`
> 参数整定与双目测距 v1.0 立体校正前置（《双目深度估计思路.md》§3.1）。
> 不含：RTSP 球机标定、板上标定文件加载（后续任务）。

## 1. 背景与目标

视觉链路需要把像素偏差换算为角度偏差，物理前提是相机内参（fx、fy、cx、cy）
与畸变系数；双目测距 v1.0 的首要前置是内参 + 畸变 + 左右目旋转平移 R/T。
厂商标定数据尚无答复（P2），本轮自建离线标定工具，一次采集同时产出三类参数。

标定在 Windows 电脑进行：双目模组为 USB UVC 设备，可直接插 Windows；
采集档位与生产链路一致（SBS 2560×720@30 MJPG，拆左右各 1280×720），
内参在该分辨率下直接可用。

## 2. 代码组织

```
tools/camera_calibration/
├── 相机标定工具.md            # 中文使用文档：打印要求、采集姿势、验收阈值、排障
├── generate_charuco_board.py  # 生成 ChArUco 打印板 PNG（A4 排版）
├── capture_stereo_charuco.py  # Windows 实时交互采集（SBS 拆目+检测叠加+空格采帧）
├── calibrate_stereo.py        # 离线标定（读 captures/，可反复重跑）
└── captures/                  # 采集图片（.gitignore 不入库）
```

拆分理由：标定参数调整（格子实测边长输错、坏图剔除、RMS 不达标重来）需要
反复重跑，采集最贵——一次采集、多次标定。

## 3. 标定板

- ChArUco（棋盘格+ArUco 复合）：允许部分出画/遮挡，姿态受限时仍贡献约束。
- 默认参数：`DICT_5X5_1000`，11×8 格，格子 22mm，标记 16mm，A4 横放排版；
  全部 CLI 可改（--cols/--rows/--square-mm/--marker-mm）。
- **格子边长以打印后实测为准**（打印缩放是最大误差源，文档加粗强调）。

## 4. 采集（capture_stereo_charuco.py）

- `cv2.VideoCapture(index, cv2.CAP_DSHOW)`，设 2560×720@30、fourcc MJPG；
  打开失败/档位不符时列出可用设备号并退出。
- 每帧拆左右半幅（1280×720），各自 `CharucoDetector` 检测并叠加显示；
  空格采帧约束：**左右目同帧都检出 ≥6 个角点**才落盘。
- 屏幕提示：已采对数、画面 3×3 分区覆盖计数、最近一帧角点数；
  目标 ~25 对，覆盖全分区 + 远/中/近距离 + 多方向倾斜。
- 落盘：`captures/<会话时间戳>/left_XXX.png`、`right_XXX.png`、`meta.json`
  （分辨率、板参数、字典名、采集时刻）。Enter 结束。

## 5. 标定（calibrate_stereo.py，OpenCV 5.0）

1. 逐对图检测 ChArUco 角点；任一目角点 <6 的对跳过并计数。
2. 单目标定：`board.matchImagePoints` 取对象点 → `cv2.calibrateCamera`
   得 K_l/dist_l、K_r/dist_r 及各自 RMS。
3. 立体标定：取左右共同 charuco id 的对象点 →
   `cv2.stereoCalibrate(CALIB_FIX_INTRINSIC)` 得 R、T、立体 RMS。
4. `stereoRectify` + `initUndistortRectifyMap` + `remap` 生成校正后左右拼图，
   画水平极线供目视检查。
5. 每对图复投影误差列表，误差最大的 3 对打印文件名供剔除重跑。
6. 基线校验：|T| 与标称 60mm 偏差 >10% 打印告警（提示检查格子边长）。

## 6. 输出（captures/<会话>/calibration.json）

```json
{
  "image_width": 1280, "image_height": 720,
  "board": {"type": "charuco", "dictionary": "DICT_5X5_1000",
            "cols": 11, "rows": 8, "square_m": 0.024, "marker_m": 0.018},
  "left":  {"camera_matrix": [...], "dist_coeffs": [...], "rms": 0.0},
  "right": {"camera_matrix": [...], "dist_coeffs": [...], "rms": 0.0},
  "stereo": {"R": [...], "T_m": [...], "baseline_m": 0.0, "rms": 0.0},
  "fov_deg": {"left_h": 0.0, "left_v": 0.0, "right_h": 0.0, "right_v": 0.0},
  "opencv_version": "...", "calibrated_at": "..."
}
```

- FOV 由内参推算（`2·atan(w/(2·fx))`），供 `vtc_config.h` camera 组回填占位值。
- K/dist/R/T 是测距 v1.0 立体校正全部输入；板上加载格式后续任务再定。
- 红线延续：标定完成前所有参数仅限回放/SITL 验证；标定后《双目深度估计思路.md》
  §5.3 误差表按实测 F 重算。

## 7. 验收阈值

- 单目 RMS < 1.0px（<0.5 为优）；立体 RMS < 1.0px。
- 校正拼图极线目视对齐（同名点在同一水平线上）。
- |T| ≈ 60mm 标称基线（偏差 >10% 需排查格子边长/采集质量）。

## 8. 错误处理

- 摄像头打不开/档位设置失败：列出可用设备号，明确报错退出。
- 有效图对 <10：拒绝标定并提示补采。
- 角点不足的图对：跳过，结束汇总计数。
- meta.json 板参数与 CLI 不一致：以 meta.json 为准并提示（防采集/标定板不一致）。
