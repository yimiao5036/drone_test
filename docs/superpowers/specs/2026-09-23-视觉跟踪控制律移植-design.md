> 日期：2026-09-23 ｜ 状态：已评审冻结
> 范围：将 `visual_track_control/` 独立子库的核心控制律移植到主工程
> `include/control/` + `src/control/`（原库一行不动、保持独立构建），
> 用 2026-09-23 标定实测内参修复角度换算的主点假设问题，新增影子适配层

## 1. 阶段定位（与用户的架构对齐记录）

主工程目标跟踪为两阶段架构（《物理追踪思路.md》）：

- **远场引导**：地面站目标 WGS-84 + PX4 Home → `TargetEstimator`（NED 线性
  卡尔曼，已影子运行）→ 状态机 GPS_APPROACH。地面站目标在视觉跟踪阶段仅
  用于丢失校验与降级回退（§57），不驱动本控制律（§6.4）。
- **末端跟踪（本轮）**：视觉像素中心（角度控制）+ 双目距离（距离通道）+
  PX4 姿态 → 视觉跟踪控制律 → 速度/航向指令。
- 视觉/双目观测经 NED 转换接入正式卡尔曼是后续阶段（§6.3/§7.2），前置
  条件之一（相机标定）已于 2026-09-23 完成。

## 3. 配置并入主工程

`config/config.json` 新增 `visual_tracking` 段（tracking_config 全量字段 +
影子段），主工程 `config.cpp` 解析（缺字段/类型错/非法值抛异常，与现有
配置纪律一致）。camera 组内参与分辨率绑定校验：分辨率 ≠1280×720 时
启动报错提示需重新标定（内参只对标定档位有效）。

## 4. 影子适配层（新组件 `VisualTrackingShadow`，`include/control/`）

- **订阅** `kVisualTargetStatus`（平滑中心/状态）+ `kFlightState`（姿态）；
  **发布** `kControlIntent`（影子：无消费者，`enable_control=false` 基线不动）。
- 独立线程按 `control.frequency_hz`（默认 20Hz）固定节拍组装快照 →
  `TrackingControlLaw::Update` → 映射 `ControlIntent` 发布。
- 状态映射：`VisualTargetStatus.state==kLocked` → tracked=true，其余
  tracked=false（触发判丢刹车路径）；`is_predicted=false`；双目测距未实现，
  `distance_valid` 恒 false（走 kSlowApproach 降级支路，正好观察该路径）。
- **虚拟姿态**：`visual_tracking.shadow.virtual_attitude_when_absent`
  （默认 true）下姿态缺失/超龄时以 roll/pitch/yaw=0 填充继续计算，
  首次进入时 INFO 标注"虚拟姿态影子"；false 保持真实语义（每拍降级保持）。
- **`ControlIntent` 扩展字段** `yaw_rate_dps`（默认 0；速率式模式填写；
  现有 yaw_deg 仅位置式可用，主工程类型向后兼容演进）。
- 日志纪律：状态切换日志（控制律内已有）+ 影子组件节流 INFO 摘要
  （10s：模式/β/α/输出速度/航向指令）；热路径零日志。

## 5. 明确不做

- 不接 Px4Link、不产生真实控制输出；`enable_control=false` 基线不动；
- 畸变不进角度换算（本轮只用内参；畸变由测距 v1.0 立体校正承担）；
- `visual_track_control/` 原库冻结存档、保持独立构建，不修改；
- 双目测距、TargetEstimator 视觉/双目融合（后续阶段）。

## 6. 测试

- 移植的 78 用例全部通过（随新接口改）；
- 新增用例：
  - 内参式角度换算：cx/cy 偏中心时偏移符号与量值正确（cy=532.1 处
    像素 → α=0；画面中心 360 → α≈+9.7° 向下）；
  - 影子组件：虚拟姿态开/关两态、仅 kLocked 输出正常控制、kLost →
    kBrakeHover 映射、distance_valid=false 走 kSlowApproach；
- WSL2 全量 0 警告 + ctest 全绿；板上影子观察留待后续。
