## 2. 数据流

```text
kDecodedFrameLeft  → YoloDetector（现有左目实例，配置不变）→ kDetectionLeft
kDecodedFrameRight → YoloDetector（新增右目实例）          → kDetectionRight
                          ↓ 时间邻接配对（pair_window_ms，默认 ±20ms）
                     StereoRanger（新组件，perception）
                     匹配 → 去主点视差 → Z 三角测量 → 有效性 → 滤波
                     → 在线 |Δy| 校验统计
                          ↓
              Topic<StereoTargetDistance> kStereoTargetDistance
                          ↓
              VisualTrackingShadow 订阅 → distance_valid 接通（影子距离闭环）
```

## 3. 核心算法（StereoRangerCore，纯算法、依赖注入、GTest 全量可测）

### 3.1 去主点视差（本轮标定的直接后果，思路文档原方案没有的坑）

两目 cx 实测差 54px：直接用 `bbox_xL − bbox_xR` 算同侧边缘视差，近距
（D≈20px）时主点差会把视差符号搞反。**一律先去各自主点**：

```text
uL = (xL − cxL) / fxL     uR = (xR − cxR) / fxR     （同侧左边缘）
D_norm = uL − uR          （归一化视差）
Z = B / D_norm            （fxL≈fxR 时退化为 F·B/D）
X_C = B/2 · (uL + uR) / D_norm     R = sqrt(X_C² + Y_C² + Z²)
```

|Δy| 校验同样在去 cy 坐标下计算：Δy = (yL − cyL) − (yR − cyR)。

### 3.2 匹配（思路文档 §6 原样）

硬约束：类别一致、|Δy| ≤ τ_y（去 cy，默认 2px ⚠板上回填）、
归一化视差对应距离 ∈ [distance_min_m, distance_max_m]、框高比
|hL−hR|/max ≤ τ_h（0.25）。代价 `|Δy|/τ_y + |Δh|/(τ_h·max)` 升序贪心，
cost<1 接受，一一配对。失败 → 该目标本帧无距离（valid=false 照常发布方位）。

### 3.3 有效性判定（误差表按实测重算，F·B = 1007.8×0.0601 ≈ 60.57）

δZ ≈ Z²·δD/(F·B)（δD=1px）：

| Z | D | δZ |
|---:|---:|---:|
| 3m | 20.2px | 0.15m |
| 5m | 12.1px | 0.41m |
| 8m | 7.6px | 1.06m |
| **11m** | 5.5px | **2.0m** ← δZ≤2m 边界 |
| 15m | 4.0px | 3.7m |
| 20m | 3.0px | 6.6m ← D≥3px 边界 |

判据（D≥3px 且 δZ≤2m）交集 → **有效域 ≤11m**（`distance_max_m=11` 默认，
可整定）；比思路文档 1920 占位估算（15m）收窄，为 1280 宽分辨率的代价。
域外/未匹配/超龄 → valid=false（方位字段照常有效）。

### 3.4 轻量时间滤波（思路文档 §7 原样）

Z 一阶低通（α=0.3）+ 跳变门限（|ΔZ|>5m 直接重置）；按类别+最近邻关联，
多目标全量跟踪留 v1.1。

### 3.5 在线校正质量校验（不 remap 的代价兜底）

对每个匹配对累计 |Δy|（去 cy）进滑动窗口统计，摘要日志输出 P95；
P95 > 2px 持续 → WARN（节流），提示需升级 remap（v1.1 提前）。

## 4. 组件与装配

- **StereoRangerCore**（`include/perception/stereo_ranger_core.h`）：纯算法
  类，输入左右 DetectionResult 数组 + 标定参数结构，输出
  `vector<StereoTargetDistance>`；匹配器接口注入（贪心为默认实现）。
- **StereoRanger**（`include/perception/stereo_ranger.h`）：组件壳，独立
  消费线程；双订阅（容量 2、丢最旧），按 header 接收时间 ±pair_window_ms
  邻接配对左右结果（实现期核实 YoloDetector 是否透传帧 ingress 时间戳，
  透出则升级为同帧相等判定）；节流摘要日志（配对率/有效域内占比/
  |Δy| P95/测距耗时，默认 10s）。
- **右目检测**：DroneApplication 装配第二个 YoloDetector 实例
  （配置段 `yolo_right`，默认继承 `yolo` 全部值，`npu_core_mode` 独立），
  输入接 `kDecodedFrameRight`，输出新 Topic `kDetectionRight`；现有左目
  `kDetection` 重命名不动，叠加器继续消费左目。
- **VisualTrackingShadow**：订阅 `kStereoTargetDistance`；最新一条
  valid 且未超龄（`control.distance_stale_ms`）→ distance_valid=true 并填
  target_distance_m，距离 PID 接管（影子观察）；否则维持
  no_distance_action 支路（kSlowApproach 已板上验证）。方位通道 v1.0 仍用
  VisualTargetStatus 左目中心；x_mid 字段照发，接入切换留后续（思路文档
  15.2 接入层约定）。
- 开关：`runtime.enable_stereo_ranging`（默认 false；要求
  enable_video + uvc + stereo_split + enable_visual_tracking，config.cpp
  校验依赖链）。
