# 多机任务分配与自动起飞 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按已确认规格实现 65014/65015 任务分配、65013 v2 状态扩展、机载分配助手、S2→S3→S4→S5 自动起飞、`FlightController::kBootstrap` 预授权流，以及基于 PX4 `BAT_LOW_THR` 的低电主动 S12 返航。

**Architecture:** `GroundStationLink` 只做 65014/65015/65013 的链路编解码与地址校验；`MissionStateMachine` 持有 `MissionAssignmentTracker` 纯逻辑助手，负责分配状态、预检、S3/S4 起飞编排、目标过滤和低电收口；`FlightController` 增加 `kBootstrap` 预授权态，负责 Offboard 前置原点保持流；`Px4Link` 增加参数读取，向状态机提供电池门限。`DroneApplication` 只做 Topic 绑定、命令接口注入和 `enable_control` 门禁。

**Tech Stack:** C++17、CMake、Google Test、MAVLink c_library_v2、PX4 1.17.0 SITL、WSL2 Ubuntu 24.04。

**Spec:** `docs/superpowers/specs/2026-10-22-多机任务分配与自动起飞-design.md`

- 行尾 LF；不得批量转换行尾。

## Review Focus

| 风险输入/条件 | 期望行为 | 归属任务 |
|---|---|---|
| 65014 地址错误/广播 | 忽略，不回 65015，不起飞 | Task 2 |
| 同一 `assignment_id` 重发 | 重发同一 65015，不重复进入 S3 | Task 3/4 |
| 未注入命令接口/估计输入 | 回 `control_disabled`，停在 S2 | Task 4 |
| 176 后未进入 6/0 | 超时中止，不重试；地面 armed 则 DISARM | Task 5 |
| 400 后未 armed | 中止；不进入 S4，不重复 ARM | Task 5 |
| bootstrap 先于 176/400 | 先发 kTakeoff，等待 lead 让原点保持流建立 | Task 5/6 |
| 已离地后中止 | 不空中 disarm；S12/S13，terminal | Task 5 |
| 低电/电池遥测失效 | 机载 S12，不走 PX4 RTL；地面 unavailable | Task 7/8 |
| PX4 低电参数读取失败 | 自动分配拒绝，原因 `battery_config_unknown` | Task 7/8 |
| 无 RC 自动流程 | 门禁不依赖 RC；RC 接管时停发让权 | Task 6/9 |

```cpp
enum class AssignmentPhase : uint8_t {
    kIdle, kAssigned, kTakingOff, kAirborne, kEngaged, kReturning, kTerminal,
};

class MissionAssignmentTracker {
public:
    bool Accept(const common::MissionAssignment& assignment, uint64_t now_ms);
    void BeginTakeoff(float x, float y, float z, uint64_t now_ms);
    void TakeoffComplete();
    void BeginEngage();
    void BeginReturn();
    void Terminal();
    void AbortOnGround();
    void AbortAirborne();
    bool AllowsTarget(uint32_t target_id) const;
    common::MissionAvailability Availability() const;
    AssignmentPhase Phase() const;
    bool HasActiveAssignment() const;
    uint32_t AssignmentId() const;
    uint32_t TargetId() const;
    uint8_t InterceptorType() const;
    bool ConsumedAirborneMission() const;
    void RememberResult(uint32_t assignment_id,
                        common::MissionAssignmentResult result,
                        common::MissionAssignmentReason reason);
    bool WasHandled(uint32_t assignment_id,
                    common::MissionAssignmentResult* result,
                    common::MissionAssignmentReason* reason) const;
    // 原点
    float OriginX() const; float OriginY() const; float OriginZ() const;
};
```

规则：

- `Accept` 仅 `kIdle`，`target_id != 0`；

- `RememberResult` 保存最近 `assignment_id` 的结果，供重复消息重发；
- 所有时间由调用方传入，助手不读时钟、不访问 Topic、不发日志（或只提供 reason）。
