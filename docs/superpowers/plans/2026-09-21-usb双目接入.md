# USB 双目摄像头接入（采集/解码/左右拆分）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按设计文档做到 B 层：`/dev/video0` UVC 采集（2560×720@30 MJPG SBS）→ VideoDecoder MJPG 解码 → StereoFrameSplitter 左右拆分 → 左目进现有 YOLO/叠加/图传链路出图，右目发独立 Topic 仅统计；与现有 RTSP 链路按 `camera_source` 配置二选一切换。

**Architecture:** 新增 `UvcCameraReceiver`（实现既有 `ICameraReceiver` 接口，V4L2 mmap 直采）与 `StereoFrameSplitter`（独立组件，RGA 裁剪优先、逐行 memcpy 回退）；`VideoDecoder` 仅加 `kMjpeg` 分派；`DroneApplication` 的 `camera_` 成员改为接口指针按配置多态创建，`stereo_split=true` 时下游改绑拆分器左目输出。RTSP 链路行为完全不动。

**Tech Stack:** C++17、V4L2（mmap/ioctl，无第三方依赖）、FFmpeg（mjpeg 软解/可选 mjpeg_rkmpp 硬解）、librga（DRONE_HAVE_RGA_DMA 条件编译）、nlohmann/json、Google Test。

**Spec:** `docs/superpowers/specs/2026-09-21-usb双目接入-design.md`（权威设计，本计划按其落地）；硬件事实见 `docs/双目硬件事实确认记录.md`。

### Task 2: UvcCameraReceiver（新组件）

**Files:**
- Create: `include/video/uvc_camera_receiver.h`
- Create: `src/video/uvc_camera_receiver.cpp`

**Interfaces:**
- `UvcCameraReceiverConfig`：`device="/dev/video0"`、`width=2560`、`height=720`、`fps=30`、`buffer_count=4`（V4L2 mmap 缓冲数）、`reconnect_delay{3000ms}`。构造校验（抛 `std::invalid_argument`）：device 非空、width/height/fps>0、buffer_count>=2、reconnect_delay>=0。
- `UvcCameraReceiver final : public ICameraReceiver`（PIMPL，头文件零 V4L2 依赖）；`StreamOutput()` 复用 `common::topics::kCameraStream` 语义。

**关键实现点：**

- 打开序列：`open(O_RDWR|O_NONBLOCK|O_CLOEXEC)` → `VIDIOC_QUERYCAP`（须含 Video Capture + Streaming）→ `S_FMT(MJPG, w, h)` → **`G_FMT` 回读校验**（必须拿到配置的 2560×720 MJPG，否则 Start 失败，防固件错档）→ `S_PARM(timeperframe=1/fps)`（尽力而为，失败仅 WARN）→ `REQBUFS/MMAP/QBUF` → `STREAMON`。
- 采集线程：`poll(fd, POLLIN, 100ms)` 定 tick（Stop 响应 ≤100ms）；帧就绪 `DQBUF` → 构成 `EncodedFrame`（`codec=kMjpeg`、`is_key_frame=true`、`parameter_sets` 空、`data`=JPEG 字节）→ 发布 → `QBUF` 归还。
- 时间戳：`capture_time_ms` 与 `header.source_time_ms` 取 v4l2 buffer 的 `V4L2_BUF_FLAG_TIMESTAMP_MONOTONIC` 时间戳（monotonic/soe，与主机单调时钟同域，实证可用，非伪造）；`header.receive_time_ms` 取 dequeue 后的主机单调时钟。无 MONOTONIC 标志时两者留 0。
- 断流/拔线：无帧累计 1s（10 个 100ms tick）或 DQBUF/S_FMT 等 ioctl 报 EIO → `ErrorCount++`、关流（STREAMOFF/munmap/close）、按 `reconnect_delay` 重开（`ConnectCount` 语义与 RTSP 版对齐）；重开失败仅计错与节流 WARN，循环直到 Stop。
- fd 与 mmap 缓冲 RAII；`Stop()` 幂等（置标志 → join → 关设备）；`Start()` 首次打开失败返回 false（ERROR），启动后运行期失败走重连循环。
- 日志：建连成功/重连（INFO）、断流/回读校验不符（WARN 节流）、Start 失败（ERROR）；逐帧零日志。

- [ ] **Step 2: 写实现**（匿名命名空间复刻 `SteadyNowMs/ShouldLogThrottled` 模式；V4L2 调用封装 `OpenDevice/CloseDevice/CaptureLoop`）。

### Task 4: StereoFrameSplitter（新组件）

**Files:**
- Create: `include/video/stereo_frame_splitter.h`
- Create: `src/video/stereo_frame_splitter.cpp`

**Interfaces:**
- `StereoFrameSplitterConfig`：`width=2560`（全幅 SBS 宽，偶数）、`height=720`、`pool_capacity=8`（左右各自输出池）、`input_queue_capacity=1`、`stride_alignment=64`、`prefer_rga=true`。构造校验：width 为偶数且 >0、height>0、pool_capacity>0、input_queue_capacity>0、stride_alignment>0。
- 具体类（同 `FrameCompositor` 惯例，不设抽象接口）：`Start/Stop/IsRunning`、`SetInput(Topic<FrameHandle>&)`、`LeftOutput()/RightOutput()`；计数 `LeftFrameCount/RightFrameCount/LeftDroppedCount/RightDroppedCount/ErrorCount/RgaFallbackCount`。

**关键实现点：**

- 独立消费线程订阅 `kDecodedFrame` 全幅（队列容量 1、`kDropOldest`——只处理最新帧）；`WaitTakeFor(100ms)` + `Stop` 经 `input_sub.Reset()` 唤醒（对齐 compositor 停机模式）。
- 启动时按 `width/2 × height` NV12、stride 64 对齐各建左右 `VideoFramePool`（`std::make_shared`，INFO 生命周期日志）。
- 输入校验：句柄无效 / 格式非 NV12 / 宽高与配置不符 → 丢弃并 `ErrorCount++`（ERROR 节流 1+100）。
- 裁剪：左目 src rect `(0,0,w/2,h)`、右目 `(w/2,0,w/2,h)`。`prefer_rga && DRONE_HAVE_RGA_DMA` 时 `wrapbuffer_virtualaddr` 包源全幅（`RK_FORMAT_YCbCr_420_SP`，wstride/hstride 取源 stride，注意六参数顺序 width/height/format/wstride/hstride）与目标半幅 → `imcrop(src, dst, rect)`；失败计 `RgaFallbackCount`（WARN 节流）并回退逐行 memcpy；x86 无 RGA 直接 memcpy（Y 面 h 行 + UV 半面 h/2 行，按源/目的 stride，UV 行宽 = width/2）。
- 帧元数据：两池 `Acquire(ingress)` 透传 `pipeline_ingress_time_ms`；裁剪完成后 `SetTiming(拆分完成时刻, ingress)`；序号由左右各自池分配（不透传源序号，左右一致性以计数器与 ingress 核对）。
- 左右独立容错：一目池满只计该目 Dropped，另一目照常发布；右目 Topic 本轮无订阅者（句柄入 Topic 后无消费者自动归还，仅计数）。
- 左右目对应关系：左半幅暂任取为主用目（未实证），代码注释标注测距阶段若相反仅交换两个裁剪 rect。

- [ ] **Step 1: 写头文件与实现**（PIMPL 惯例同 compositor；RGA 调用 `#ifdef DRONE_HAVE_RGA_DMA` 隔离）。
- [ ] **Step 2: CMake 挂接**：`drone_video` 源列表追加 `src/video/stereo_frame_splitter.cpp`（RGA 编译宏/头文件/库已由 drone_video 既有块覆盖）。
