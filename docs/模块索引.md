## 9. DroneApplication实际创建条件

| 组件 | 创建条件 |
|---|---|
| CameraReceiver、VideoDecoder、YoloDetector、FrameCompositor、VideoSender | `runtime.enable_video=true` |
| Px4Link | `runtime.enable_px4=true` |
| GroundStationLink | `runtime.enable_ground_station=true` |
| TargetEstimator | `enable_target_estimator=true`且PX4、地面站组件均已创建 |
| VisualTargetMonitor | `enable_visual_monitor=true`且视频链路（YoloDetector）已创建 |
| MissionStateMachine | PX4和地面站组件均已创建 |
| HealthManager | 总是创建，只注册实际存在的数据源 |
| FlightController | 当前永不创建 |

配置加载期还会拒绝：

- 地面站启用但PX4关闭；
- TargetEstimator启用但地面站或PX4关闭；
- VisualTargetMonitor启用但视频链路关闭；
- `enable_control=true`；
- 所有数据链路都关闭。
