## 9. DroneApplication实际创建条件

| 组件 | 创建条件 |
|---|---|
| CameraReceiver、VideoDecoder、YoloDetector、FrameCompositor、VideoSender | `runtime.enable_video=true` |
| Px4Link | `runtime.enable_px4=true` |
| GroundStationLink | `runtime.enable_ground_station=true` |
| TargetEstimator | `enable_target_estimator=true`且PX4、地面站组件均已创建 |
| TargetEstimator 视觉融合输入 | `enable_visual_position_fusion=true`（另要求双目测距+PX4）且 StereoRanger 已创建，装配期接 `StereoRanger::DistanceOutput()` |
| VisualTargetMonitor | `enable_visual_monitor=true`且视频链路（YoloDetector）已创建 |
| StereoRanger | `enable_stereo_ranging=true`且依赖链齐全（视频链路+camera_source=uvc+stereo_split+enable_visual_tracking）；预置校正矩阵文件缺失/不自洽时启动失败 |
| MissionStateMachine | PX4和地面站组件均已创建 |
| HealthManager | 总是创建，只注册实际存在的数据源 |
| FlightController | MissionStateMachine 已创建即装配（阶段四 Task 6 起）；`Px4Link::SetInput` 绑定与 PX4 快照源注入仅 `enable_control=true` |

配置加载期还会拒绝：

- 地面站启用但PX4关闭；
- 视觉融合启用但目标估计器/双目测距/PX4任一关闭；
- TargetEstimator启用但地面站或PX4关闭；
- VisualTargetMonitor启用但视频链路关闭；
- StereoRanging启用但视频链路、uvc、stereo_split或visual_tracking任一关闭；
- `enable_control=true`但PX4或地面站关闭，或`controller`节`Validate()`不通过；
- 所有数据链路都关闭。
