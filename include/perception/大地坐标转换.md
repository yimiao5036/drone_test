# 大地坐标转换实现文档

## 功能职责

`geodetic_converter.h/.cpp`把地面站WGS-84经纬度转换为以PX4 Home为原点的局部NED坐标。当前只服务于单目标估计第一阶段，不负责高度基准转换、地图投影、跨洲导航或坐标系时间管理。

## 接口与数据流

```cpp
std::optional<LocalNedCoordinate> GeodeticToLocalNed(
    const GeodeticCoordinate& reference,
    const GeodeticCoordinate& target);
```

```text
PX4 Home(WGS-84/MSL) + GroundStationTarget(WGS-84/同高度基准)
→ GeodeticToLocalNed
→ north/east/down（米）
```

非法纬度、经度、NaN或Inf返回`std::nullopt`。

## 关键实现点

- 使用WGS-84半长轴`6378137.0m`和扁率`1/298.257223563`计算参考纬度处的子午圈、卯酉圈曲率半径。
- 在参考点局部切平面上计算N/E；经度差归一化到`[-pi, pi]`，避免跨180度经线走长路径。
- D轴遵循NED向下为正：`down = reference_altitude - target_altitude`。
- 该实现是任务局部区域近似，不引入GeographicLib依赖，减少RK3588部署依赖链。若任务范围扩大到局部切平面误差不可接受，应替换为经过验证的GeographicLib `LocalCartesian`，接口不变。
- 函数不判断MSL/AGL/椭球高度是否兼容；调用方必须先做高度有效位和基准校验。第一阶段只有地面站`alt_reference=1(MSL)`才与PX4 Home MSL高度组合。

## 日志行为

纯数学函数不打日志。输入拒绝由调用它的`TargetEstimator`按第1次及每100次节流记录。

## 测试方式

```bash
cmake -S . -B build
cmake --build build -j$(nproc)
./build/target_estimator_test --gtest_filter='GeodeticConverterTest.*'
```

测试覆盖同点归零、北/东/下符号及数量级、非法纬度拒绝。

## 排查/修改要点

- 东向误差首先检查角度是否重复转换为弧度、经度差是否经过归一化。
- 垂直方向相反时检查NED“向下为正”约定。
- 不得把AGL或WGS84椭球高度直接与PX4 Home MSL相减。
- 修改坐标算法后必须同步复核地面站目标、PX4 Home字段和`TargetState.header.frame_id=3`契约。
