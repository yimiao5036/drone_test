# 线性目标卡尔曼滤波器实现文档

## 功能职责

`LinearTargetKalmanFilter`维护单一目标在局部NED中的位置和速度，采用恒速度线性卡尔曼模型平滑地面站位置并进行短时预测。它不处理WGS-84转换、多目标关联、视觉检测框、目标ID选择、消息队列和控制输出。

## 接口与数据流

状态等价于：

```text
x = [N, E, D, VN, VE, VD]
```

实现上拆成三个独立的二状态轴：

```text
[N,VN] [E,VE] [D,VD]
```

主要接口：

```cpp
bool Initialize(const LinearTargetMeasurement& measurement);
bool Predict(double dt_seconds);
bool Update(const LinearTargetMeasurement& measurement);
LinearTargetKalmanState State() const;
LinearTargetKalmanState PredictedState(double dt_seconds) const;
void Reset();
```

水平N/E是初始化必需观测；D轴可在后续收到有效MSL高度时独立初始化。

## 关键实现点

- 状态转移为`position += velocity * dt`，`dt`来自观测单调时钟，不固定为帧数。
- 过程噪声采用白噪声加速度模型：

```text
Q = sigma_a^2 * [[dt^4/4, dt^3/2],
                 [dt^3/2, dt^2]]
```

- 位置和可选速度采用标准线性测量更新；N/E共享水平位置标准差，D使用垂直标准差。
- 未提供速度时以0作为初始均值，但使用较大的`initial_velocity_std_mps`表示不确定，而不是宣称目标静止。
- `PredictedState()`复制滤波器后预测，不推进内部观测时刻，避免周期发布把状态推进到未来后拒绝有传输延迟的新观测。
- 预测单步限制为0～10秒；实际有效地面站目标的协议有效期不超过5秒，超过有效期的输出由上层标为无效。
- 第一阶段忽略N/E/D轴间相关项，属于块对角六维线性模型。后续视觉方向等非线性原始测量不直接塞入本滤波器；必须先转换为NED位置，或经评审升级估计器。
- JSON中的噪声参数是影子阶段初值，尚未通过真实目标录制数据整定，禁止据此开放控制。

## 日志行为

本类为纯算法层，不依赖spdlog、不打日志。参数错误由构造函数抛`std::invalid_argument`，运行期非法观测返回`false`，由`TargetEstimator`统一节流记录。

## 测试方式

```bash
cmake -S . -B build
cmake --build build -j$(nproc)
./build/target_estimator_test --gtest_filter='LinearTargetKalmanFilterTest.*'
```

测试覆盖带速度初始化和预测、后续高度轴初始化、非法dt拒绝。

## 排查/修改要点

- 预测发散时检查时间单位是否把毫秒误作秒、过程加速度噪声是否过大。
- 位置过度滞后时检查测量标准差和过程噪声的相对关系，不得只为跟随更快而无依据减小测量噪声。
- 修改协方差公式后必须验证对称性、非负方差和长时间数值稳定性。
- 不得搬入`target_tracker`的IoU、多轨道、固定`dt=1`或检测框尺寸状态。
