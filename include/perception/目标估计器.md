# 目标估计器实现文档

## 功能职责

`TargetEstimator`是正式工程单目标状态估计部件。第一阶段认为地面站`GroundStationTarget.target_id`就是任务目标，使用PX4 Home作为局部NED原点，将地面站经纬度转换为NED后输入恒速度线性卡尔曼滤波，周期发布影子`TargetState`。

当前做：

- 消费地面站单目标和PX4状态；
- 等待有效PX4 Home；
- WGS-84/MSL到局部NED转换；
- 可选地面站速度更新；
- 目标ID/Home变化重置；
- 时效、重复/乱序和非法输入检查；
- 周期发布预测状态。

当前不做：

- 不消费YOLO、双目深度或光流；
- 不做多目标ID、IoU关联或主目标选举；
- 不产生`ControlIntent`、`Px4Setpoint`或任何MAVLink控制命令；
- 不改变`target_tracker/`独立目录；
- 不把AGL或WGS84椭球高度伪装成MSL高度。

## 接口与数据流

```cpp
class TargetEstimator : public ITargetEstimator {
    bool Start();
    void Stop();
    void SetGroundTargetInput(Topic<GroundStationTarget>&);
    void SetFlightStateInput(Topic<FlightStateSnapshot>&);
    Topic<TargetState>& EstimatedOutput();
    TargetState LastState() const;
};
```

正式接线：

```text
GroundStationLink::TargetOutput() ─┐
                                   ├→ TargetEstimator → kEstimatedTarget（影子）
Px4Link::StateOutput() ────────────┘
```

第一阶段`MissionStateMachine`仍直接消费原始`GroundStationTarget`；估计输出并行运行，不参与状态推进和控制。

输出约定：

- `header.frame_id=3`：PX4 Home原点的局部NED；
- `pos_x/pos_y/pos_z=N/E/D`；
- `valid`表示水平状态存在且地面站目标仍在协议剩余有效期内；
- 地面站高度无效或不是MSL时，`pos_z_m/vel_z_mps=NaN`，水平状态仍可影子观察；
- `last_observed_ms`是按`receive_time_ms-transport_age_ms`恢复的飞机单调时钟观测时刻；
- `confidence`第一阶段仅表示剩余有效期比例，不是分类概率或完整融合置信度。

## 关键实现点

- 组件必须在地面站/PX4生产者之前启动，避免漏掉首个Home或目标；停止时在生产链停止后退出。
- Home变化会重置滤波器，禁止在不同局部NED原点间延续旧状态。
- `target_id`变化或旧状态已过期时重新初始化，不把两个任务目标混入同一滤波状态。
- 同一地面站boot ID内拒绝重复/倒序`update_seq`；拒绝早于当前滤波时刻的观测。
- 地面站可选字段位遵循65010协议：bit0高度、bit1/2/3速度N/E/D、bit5水平精度、bit6垂直精度。
- 高度只有`bit0=1 && alt_reference=1(MSL)`时有效；否则D轴不初始化。
- 目标过期后发布一次`valid=false`快照用于观测失效变化，随后停止周期发布，直到收到新观测；该快照不能被控制使用。
- 配置`runtime.enable_target_estimator=true`依赖PX4和地面站同时启用；`enable_control=false`安全门禁保持不变。

## 日志行为

- INFO：创建/启动/停止/销毁，第一条和每100条接受观测（带N/E/D、VN/VE用于影子核对），目标ID变化导致重置；
- WARN：Home变化重置、目标状态首次进入过期，非法/过期/重复/乱序观测按第1次和每100次节流，等待Home也节流；
- ERROR：输入未绑定导致启动失败；
- 不逐周期记录预测状态，不在100ms发布热路径打日志。

## 配置

`config/config.json`：

```json
"runtime": {
  "enable_target_estimator": true,
  "enable_control": false
},
"target_estimator": {
  "ground_target_queue_capacity": 4,
  "flight_state_queue_capacity": 2,
  "publish_interval_ms": 100,
  "process_acceleration_std_mps2": 8.0,
  "initial_velocity_std_mps": 20.0,
  "velocity_measurement_std_mps": 5.0,
  "default_horizontal_accuracy_m": 10.0,
  "default_vertical_accuracy_m": 15.0,
  "minimum_measurement_std_m": 0.5
}
```

这些噪声参数是影子阶段初值，需要通过固定录制输入比较创新、残差、速度和预测误差后整定。

## 测试方式

```bash
cmake -S . -B build
cmake --build build -j$(nproc)
./build/target_estimator_test
ctest --test-dir build --output-on-failure
```

测试覆盖：

- 输入未绑定时拒绝启动；
- PX4 Home + 地面站目标转换为NED并发布；
- 有效地面站速度进入状态；
- 高度无效时垂直输出NaN；
- 目标有效期结束后发布一次无效快照；
- 目标ID变化重新初始化；
- WGS-84转换和线性滤波纯算法边界。

香橙派验证应确认日志出现目标估计接受计数，抓取`LastState`或临时诊断订阅核对N/E/D符号和数量级；本阶段不得通过接线验证飞行动作。

## 排查/修改要点

- 一直没有输出：检查PX4是否已上报`home_valid=true`，以及地面站目标是否在剩余有效期内。
- N/E数量级错误：检查degE7到度的`1e-7`转换和Home是否正确。
- D轴为NaN：检查65010高度有效位和`alt_reference=1`；这是保守行为，不得改成0。
- 速度异常：检查地面站速度有效位，未置位字段不得参与更新。
- 后续接入双目时，应新增统一的局部NED位置观测消息，再复用同一滤波器；视觉像素或深度标量不能未经坐标转换直接更新N/E/D。
- 正式控制接入前必须增加异常值创新门限、录制数据整定、SITL和拆桨台架验证。
