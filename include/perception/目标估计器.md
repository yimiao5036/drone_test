# 目标估计器实现文档

## 功能职责

`TargetEstimator`是正式工程单目标状态估计部件。以地面站`GroundStationTarget.target_id`为任务目标，使用 **EKF 投影参考锚点**（`GPS_GLOBAL_ORIGIN` #49 的 `ref_*`，即 PX4 `MAV_FRAME_LOCAL_NED` 原点、设定值执行帧的原点）作为局部NED原点，将地面站经纬度转换为NED后输入恒速度线性卡尔曼滤波，周期发布影子`TargetState`。

> **方案 C 已落地（2026-10-16）**：此前以 PX4 Home 为原点，与执行帧（锚点）存在
> 固定偏置 H（Home 底面跟随/解锁冻结导致）。现换算一律以锚点为原点（H 定义上归零），
> 重置触发由"Home 变化"改为"**锚点变化**"（EKF 原点重设，罕见）；Home 变化降级为
> 纯诊断 WARN。背景见 `docs/方案C锚点基准实施清单.md` 与
> `include/control/flight_controller.md`「Home 漂移对控制的影响」。
第二阶段（2026-10-12，可选开关）接入双目视觉观测：相机系三维位置经安装外参与
PX4 姿态/自身位置转换为局部 NED 位置观测，更新同一滤波器（`docs/物理追踪思路.md` §6.3）。

当前做：

- 消费地面站单目标和PX4状态；
- 等待有效 EKF 锚点（`ned_ref_valid`，锚点未到不处理目标）；
- WGS-84/MSL到局部NED转换（以锚点为原点）；
- 可选地面站速度更新；
- 可选双目视觉NED观测融合（`visual.enabled`，由 `runtime.enable_visual_position_fusion` 装配）；
- 目标ID/**锚点**变化重置；
- 时效、重复/乱序和非法输入检查；
- 周期发布预测状态。

当前不做：

- 视觉观测**不初始化**滤波器、**不延展**地面站有效期（过期政策归状态机，禁止无限预测）；
- 不消费光流；
- 不做多目标ID、IoU关联或主目标选举（同一帧多框只接受首条有效观测）；
- 不产生`ControlIntent`、`Px4Setpoint`或任何MAVLink控制命令；
- 不改变`target_tracker/`独立目录；
- 不把AGL或WGS84椭球高度伪装成MSL高度。

## 接口与数据流

```cpp
class TargetEstimator : public ITargetEstimator {
    bool Start();
    void Stop();
    void SetGroundTargetInput(Topic<GroundStationTarget>&);
    void SetFlightStateInput(Topic<FlightStateSnapshot>&);
    void SetVisualDistanceInput(Topic<StereoTargetDistance>&);  // 可选，见下
    Topic<TargetState>& EstimatedOutput();
    TargetState LastState() const;
    uint64_t VisualUpdateCount() const;
    double LastVisualInnovationM() const;  // 视觉创新诊断（交接门限用）
};
```

正式接线：

```text
GroundStationLink::TargetOutput() ─┐
Px4Link::StateOutput() ────────────┼→ TargetEstimator → kEstimatedTarget（影子）
StereoRanger::DistanceOutput() ────┘  （视觉融合开启时，可选第三输入）
```

视觉输入接线条件：`runtime.enable_visual_position_fusion=true`（依赖
`enable_target_estimator && enable_stereo_ranging && enable_px4`，配置期校验）；
开关开但未接线时 `Start()` 失败（fail-fast）。视觉融合的坐标转换由
`visual_ned_converter` 纯函数完成（见 `include/perception/visual_ned_converter.md`）。

阶段四起`MissionStateMachine`经`SetEstimationInputs`消费本输出（S5 位置引导）；
生产 `DroneApplication` 尚未接线，估计输出当前保持影子/验收工具使用。

输出约定：

- `header.frame_id=3`：EKF 锚点原点的局部NED（与 PX4 设定值执行帧 `MAV_FRAME_LOCAL_NED` 同源；方案 C，2026-10-16）；
- `pos_x/pos_y/pos_z=N/E/D`；
- `valid`表示水平状态存在且地面站目标仍在协议剩余有效期内；
- 地面站高度无效或不是MSL时，`pos_z_m/vel_z_mps=NaN`，水平状态仍可影子观察；
- `velocity_valid_mask`（P3，2026-10-19）：逐轴速度前馈可用位，bit0=N、bit1=E、
  bit2=D（`common::kVelocityValid*`）；0=无可用速度。地面站该轴速度有效位
  （`validity_flags` bit1/2/3）优先且立即生效；缺失轴回退卡尔曼自算速度，需自
  滤波器重置后累计 `min_velocity_position_updates`（默认 5，`target_estimator`
  配置节）次位置更新（地面站/视觉，初始化计 1 次）。水平/垂直分别计数、逐轴
  独立；目标过期或滤波器重置时整体清零。注意该位表达“可用于前馈”，不代表
  速度精度；KF 回退仅按更新次数门槛，协方差判据留作后续。
- `last_observed_ms`是按`receive_time_ms-transport_age_ms`恢复的飞机单调时钟观测时刻；
- `confidence`第一阶段仅表示剩余有效期比例，不是分类概率或完整融合置信度。

`LastVisualInnovationM()`（诊断接口，阶段四 Task 8 起）：最近一次**接受的**视觉观测
与卡尔曼预测的水平创新距离（米）＝观测历元处预测位置到观测位置的 N/E 水平距离
（`Update` 之前的差异，更新后差异会被滤波修正吃掉，不能代表创新）。无有效视觉
更新（从未接受、锚点变化/target_id 变化重置滤波器后）返回 **NaN**——调用方
（状态机交接判据）必须把 NaN 当作"无值"而不是"一致"。注意语义边界：地面站观测
更新滤波器后该值不随之失效（它是"最近一次视觉观测的创新"），持续被视觉融合
追赶的伪目标会让创新逐渐变小，因此门限只在锁定初期有效；帧号级新鲜度核对
（创新与当前 `frame_sequence` 对应）留作后续加固项。

## 关键实现点

- 组件必须在地面站/PX4生产者之前启动，避免漏掉首个锚点（#49）或目标；停止时在生产链停止后退出。
- **锚点变化**（EKF 原点重设，罕见）会重置滤波器，禁止在不同局部NED原点间延续
  旧状态；Home 变化不再重置（方案 C，2026-10-16）。
- `target_id`变化或旧状态已过期时重新初始化，不把两个任务目标混入同一滤波状态。
- 同一地面站boot ID内拒绝重复/倒序`update_seq`；**视觉融合关闭时**拒绝早于当前滤波时刻的观测；**开启时**该情形降级为原地更新（`dt=0`，不回溯 Predict）——视觉更新会把状态时刻推前，直接拒绝会让地面站链路在有效期内饿死，降级误差上界≈目标速度×时间差，单独计数 `ground_degraded_out_of_order` 并节流 WARN。
- 视觉观测门禁链（顺序即设计）：`valid`且字段有限 → 观测时刻非 0/非未来/未超龄（`max_observation_age_ms`）→ 置信度下限 → 同帧只取首条 → 滤波器已初始化（否则跳过不计错误）→ 地面站有效期内（否则跳过不计错误，**不延展**）→ 不早于滤波状态（视觉高频，直接丢帧不降级）→ PX4 快照存在且未超龄（`flight_state_max_age_ms`）→ 姿态有效 → 局部位置有效 → 转换有限 → `Predict`→**记录创新**→ `Update`。
- 创新在 `Update` 之前取预测态计算（`filter.Predict` 之后、`filter.Update` 之前），
  仅在更新成功后写入诊断原子量；`锚点` 变化/target_id 变化/`Start` 的重置路径
  一并清为 NaN（跨原点/跨目标的创新无意义，防陈旧值通过下游门限）。
- 视觉观测 std 模型：`σ_z = z²·σ_disparity_px / fxb_m_px`（`z=fxb/d` 误差传播；`fxb_m_px` 由装配期从双目校正矩阵拷贝，单一真源不进 JSON）；v1 水平/垂直共用 σ_z（大离轴角下不严格保守，v2 可改 `σ_z·slant/z`）。KF 内部最小 std 下限不变。
- 视觉观测时刻用 `header.source_time_ms`（左目帧产出时刻，比 receive_time 更接近观测瞬间）。
- 已知近似（影子阶段接受，均写入待验证项）：安装外参全 0 准直假设；LOCAL_POSITION_NED 原点≈HOME_POSITION；观测已过 EMA 再过 KF 的双重平滑滞后。
- 双目视觉观测的现场有效量程为 **<8m**（2026-10-20 室外实测，近距 1.9m 有效占比 99.2%）；更远目标因 `disp_min_px` ≈7.95m 量程限制得到 `valid=false`，属预期，应先确认距离再排查估计器。
- 地面站可选字段位遵循65010协议：bit0高度、bit1/2/3速度N/E/D、bit5水平精度、bit6垂直精度。
  估计器把 bit1/2/3 映射为内部 `velocity_valid_mask` 的 bit0/1/2（两套位号不同，禁止混用）。
- 高度只有`bit0=1 && alt_reference=1(MSL)`时有效；否则D轴不初始化。
- **速度前馈可用性计数（P3）**：每次被接受的 `filter.Initialize()`/`filter.Update()`
  推进水平计数；同一次更新 `measurement.down_valid=true` 才推进垂直计数。地面站
  最新接受观测的显式速度位/数值作为地面候选（新的地面观测未带速度位则候选清零）；
  视觉更新不触碰候选。`ResetFilterState()`（Start、锚点变化、target_id 变化、
  过期后重新初始化）清零计数与候选。`BuildOutputState` 按“地面优先 → KF 门限
  兜底”逐轴填 `velocity_valid_mask`，过期快照清零。
- 目标过期后发布一次`valid=false`快照用于观测失效变化，随后停止周期发布，直到收到新观测；该快照不能被控制使用。
- 配置`runtime.enable_target_estimator=true`依赖PX4和地面站同时启用；`enable_control=false`安全门禁保持不变。

## 日志行为

- INFO：创建/启动/停止/销毁，第一条和每100条接受观测（带N/E/D、VN/VE用于影子核对），目标ID变化导致重置；
- WARN 分两类（2026-10-16 方案 C 起；2026-10-20 Home 日志降噪）：
  - **锚点变化重置**：`EKF 锚点变化，目标估计器已重置局部NED滤波状态: 旧/新 + 上下文`（罕见，EKF 原点重设才出现）；
  - **Home 变化仅诊断记录**：本次启动的**首条**变化打印完整明细 `PX4 Home变化（诊断记录，估计器不重置）: 旧/新 + 上下文`；其后不再逐条打印，改为**每 30s 窗口汇总**一条 `PX4 Home变化窗口汇总（周期|停止）: 窗口时长/变化次数/首末 Home/水平范围/净漂移/高度净漂移与范围/最大单步 + 上下文`，停止时强制输出未满窗口。上下文含 GPS `gps_fix/卫星/eph/epv`、**EKF 锚点 `锚点ref=(纬度,经度,高度,收N)` 与 `局部位置=(x,y,z)`**。这样地面阶段 0.5Hz Home 刷新不再以 ≈2s 周期刷屏，同时保留首条明细与 30s 采样轨迹（PX4 在 disarmed 期间持续把 Home 贴住当前位置估计、解锁/起飞后冻结，说明见 `docs/故障排查手册.md` §12.1）；
  - 其余：目标状态首次进入过期，非法/过期/重复/乱序观测按第1次和每100次节流，**等待锚点**（`目标估计等待EKF锚点`）也节流；视觉观测拒绝带细分 reason（`视觉距离不可用/时刻为0/在未来/超龄/置信度低/同帧歧义/早于滤波状态/PX4快照超龄/姿态无效/位置无效`），地面站降级更新单独节流；
- INFO（视觉）：接受视觉观测按第1次和每100条节流（带 N/E/D、σ_z、距离、创新值）；
- 视觉跳过类（未初始化/地面站已过期）只计数不打日志，避免 30Hz 无目标期刷屏（§19 纪律）。
- ERROR：输入未绑定导致启动失败；
- 不逐周期记录预测状态，不在100ms发布热路径打日志。

## 排查/修改要点

- 一直没有输出：检查PX4是否已上报 EKF 锚点（`ned_ref_valid`，Home 变化日志里 `锚点ref=` 不为 `--`），以及地面站目标是否在剩余有效期内。
- N/E数量级错误：检查degE7到度的`1e-7`转换和锚点是否正确。
- D轴为NaN：检查65010高度有效位和`alt_reference=1`；这是保守行为，不得改成0。
- 速度异常：检查地面站速度有效位，未置位字段不得参与更新。
- 视觉融合已接入（第二阶段）：相机系位置经 `visual_ned_converter` 转 NED 后复用同一滤波器；视觉像素或深度标量未经坐标转换不得直接更新 N/E/D 的约束不变。
- 视觉更新计数一直为 0：按门禁链从上往下查——`valid`/字段有限 → 观测时刻（`source_time_ms` 是否同钟域）→ 同帧歧义 → 滤波器是否被地面站初始化 → 地面站是否已过期（不延展，属预期）→ PX4 快照新鲜度/姿态/位置有效位。
- 视觉 NED 方向系统性偏转：先查 `mount_*` 是否仍是全 0 准直假设；标定前属预期系统误差。
- 目标 NED 整体偏移：核对 LOCAL_POSITION_NED 原点与 HOME_POSITION 是否同点（EKF origin 重置会静默跳变，见 `docs/故障排查手册.md`）。
- 正式控制接入前必须增加异常值创新门限、录制数据整定、SITL和拆桨台架验证。
