# 正式主程序集成（DroneApplication）

## 功能职责

`DroneApplication`是正式进程的组件所有者和装配根，负责根据`AppConfig`创建视频、PX4和地面站数传组件、在启动前绑定Topic、按顺序启动和停止。`main.cpp`只处理配置、日志、信号和进程等待。

当前边界：

- 已装配完整视频链路；
- 已装配PX4真实串口遥测链路；
- 已装配地面站真实串口链路，订阅PX4状态并发送标准MAVLink 2遥测；
- 已装配任务状态机影子链路，订阅`GroundStationLink::TargetOutput()`、PX4状态和`HealthStatus`，发布`MissionStatus`；
- 已装配真实`HealthManager`，按配置注册视频、PX4、地面站、解码器、YOLO和图传数据源；
- 应用级健康监控线程按模块计数变化调用`ReportData()`，HealthStatus接入状态机；地面站HealthStatus输入接口已绑定，并通过65012状态协议下行；MissionStatus通过65013下行；
- 不绑定`Px4Setpoint`，不发送任何飞行控制命令；

## 接口与数据流

```cpp
class DroneApplication {
public:
    explicit DroneApplication(config::AppConfig config);
    bool Start();
    void Stop();
    bool IsRunning() const;
};
```

当前数据流：

```text
CameraReceiver → VideoDecoder → YoloDetector → FrameCompositor → VideoSender
PX4 /dev/ttyS1 → Px4Link → Topic<FlightStateSnapshot>
                                      ├→ GroundStationLink → /dev/ttyS6 → 自研地面站
                                      └→ MissionStateMachine

各模块计数 → DroneApplication健康监控线程 → HealthManager
HealthManager → Topic<HealthStatus> → MissionStateMachine / GroundStationLink
地面站目标 → GroundStationLink::TargetOutput() → MissionStateMachine::StatusOutput() → GroundStationLink
```

`GroundStationLink`拥有独立订阅队列，只消费最新飞行快照；串口设备和发送频率均由JSON配置。`MissionStateMachine`当前为安全影子阶段，只上报状态，不把目标转换为PX4控制。

## 关键实现点

- 所有Topic在任何组件`Start()`前绑定；
- 视频消费者先启动，摄像头生产者最后启动；
- 状态机先于地面站、HealthManager和PX4生产者启动，以便不遗漏后续目标及健康消息；地面站消费者先于PX4状态生产者启动；停机时先停止PX4和视频生产者，再停止健康上报线程/HealthManager，最后停止状态机和地面站消费者；
- 单模块启动失败记录降级，其他独立模块继续运行；
- 当前代码没有调用`Px4Link::SetInput()`和`SendCommand()`，因此正式程序只读遥测，不输出控制；
- Stop幂等，析构再次调用安全。

## 日志行为

INFO记录应用创建、启用模块、启动完成、停止和销毁；模块启动失败记录一次ERROR。装配层不逐帧、不逐遥测快照打印日志。

## 测试方式

开发机构建：

```bash
cmake -S . -B build
cmake --build build -j$(nproc)
ctest --test-dir build --output-on-failure
```

硬件验证：香橙派运行`./build/drone_control`，确认视频继续出图、PX4串口连接和遥测请求正常；确认串口6持续输出MAVLink 2心跳及GPS/电池/模式等状态，并检查PX4没有收到ARM、模式或setpoint控制消息。

## 排查/修改要点

- 新增组件必须先创建、再绑定、最后启动；不得在运行后临时换Topic；
- 地面站目标、任务状态机影子链路和HealthManager健康Topic已接入；新增健康数据源时必须同步配置阈值、注册逻辑和测试；
- `enable_control=false`期间禁止连接FlightController输出；
- 算法接入只增加Topic接线，不把算法逻辑写入本类；
- 跨会话实施顺序见`docs/主程序集成与数据链路实施计划.md`。
