# 地面站时间同步响应与测量工具

## 功能职责

`tools/ground_station_time_sync_responder.py`用于HM30实机验证：

- 以固定MAVLink来源`255/190`发送`MAV_TYPE_GCS`心跳；
- 响应飞机`N/25`或`N/26`发起的标准`TIMESYNC`请求；
- 主动向指定飞机发送定向`TIMESYNC`请求；
- 使用地面站主机单调时钟`time.monotonic_ns()`；
- 统计最近窗口内RTT的最小值、中位数、P95、最大值；
- 统计“飞机时钟-地面站时钟”的offset中位数与最大偏差jitter。

本工具不发送目标位置、模式切换、解锁、PX4命令或setpoint，不能用于飞行控制。

## 使用方式

依赖：

```bash
pip install -U pymavlink
```

Windows PowerShell在仓库目录执行：

```powershell
python tools/ground_station_time_sync_responder.py `
  --connection udpout:192.168.144.12:19856 `
  --aircraft-system 1 `
  --aircraft-component 25
```

当前捕网-01使用：

```text
system=1
component=25
```

火箭-01改为：

```powershell
--aircraft-system 1 --aircraft-component 26
```

按`Ctrl+C`停止。

可选参数：

```text
--heartbeat-interval 1.0
--request-interval 1.0
--summary-interval 5.0
--window-size 120
```

## 预期结果

工具端应看到：

```text
[INFO] 飞机请求响应=25 主动样本=20 超时=0 忽略=0 RTT ms[min/median/p95/max]=... aircraft-ground offset ms[median/jitter]=...
```

其中：

- `飞机请求响应`：本工具为飞机主动发起的TIMESYNC请求返回响应的次数；
- `主动样本`：地面站主动请求并收到飞机响应的有效样本数；
- `RTT`：地面站侧测得的完整往返时间；
- `offset`：工具侧语义为“飞机单调时钟-地面站单调时钟”，绝对值很大不代表异常；
- `jitter`：当前窗口offset相对中位数的最大偏差，应重点观察其稳定性。

香橙派`drone_control`日志应出现一次：

```text
地面站时间同步建立: offset_ms=... rtt_ms=... jitter_ms=... samples=5
```

飞机日志里的offset语义与工具相反：

```text
飞机端offset = 地面站时钟 - 飞机时钟
工具端offset = 飞机时钟 - 地面站时钟
```

两者应近似互为相反数，但采样时刻和滤波窗口不同，不要求逐样本完全相等。

建立后飞机请求周期由快速采样切换到稳定保持周期。停止工具后，超过配置的同步超时应出现：

```text
地面站时间同步超时: previous=SYNCHRONIZED timeout_ms=5000
```

当前只验证时间同步，不会发布`GroundStationTarget`，也不会启用控制。

## TIMESYNC字段

飞机请求：

```text
tc1=0
ts1=飞机请求单调时间
target=255/190
```

工具响应：

```text
tc1=地面站响应单调时间
ts1=镜像飞机请求时间
target=请求飞机的system/component
```

地面站主动请求：

```text
tc1=0
ts1=地面站请求单调时间
target=指定飞机system/component
```

飞机响应：

```text
tc1=飞机响应单调时间
ts1=镜像地面站请求时间
target=255/190
```

## 建议采样步骤

1. 先启动更新后的`drone_control`；
2. 启动本工具并确认飞机请求响应数和主动样本数都增长；
3. 连续运行至少10分钟；
4. 保存终端输出；
5. 记录RTT的median、P95、max以及offset jitter；
6. 暂停工具超过5秒，确认飞机时间同步超时；
7. 恢复工具，确认飞机重新进入`SYNCHRONIZED`；
8. 根据实测分布调整JSON门限，再进行第二轮验证。

## 排查要点

- 样本数不增长：检查HM30 UDP地址、Windows防火墙、飞机是否收到`255/190`心跳，以及`ground_station.time_sync.enabled`是否为true。
- 报`pymavlink`不支持目标扩展字段：执行`pip install -U pymavlink`。旧生成代码只有`tc1/ts1`，不能满足多机精确响应。
- 飞机一直`ACQUIRING`：检查响应来源是否确实为`255/190`、target是否回填请求飞机身份、RTT是否超过`max_rtt_ms`。
- `主动样本=0`但`飞机请求响应`增长：飞机端可能未响应地面站主动请求，检查是否部署了包含双向TIMESYNC响应的新版本。
- offset数值很大不一定异常：两端单调时钟起点不同；应关注offset是否稳定、jitter和RTT是否合理。
- 本工具只用于测试，正式地面站必须按同一协议实现并以`component:system`维护每架飞机状态。
