# tune_report.py —— 控制律整定指标报告

> 配套 `--sitl-stage4-tune`（`px4_link_smoke`）使用：读取整定 CSV，按阶段/阶跃段
> 计算三通道整定指标并打印 PASS/FAIL。纯 stdlib。

## 用法

```bash
python3 tools/tune_report.py logs/stage4_tune_<时间戳>.csv
# 退出码 0 = 全部指标达标；1 = 存在不达标项/数据缺失
```

## 指标定义（首次定义，2026-10-14；数值经维护者评审）

**航向通道**（`step_lateral` 段，横向 E ±2/±4m 阶跃）：

| 指标 | 定义 | 验收值 | 理由 |
|---|---|---|---|
| 收敛时间 | 段起点到 \|β\|≤0.5° 且保持 2s | ≤4.0s | 30dps 限幅纯旋转 ≥1.3s + slew 爬升 + PX4 响应，一倍裕度 |
| 变号次数 | β 过零并在另一侧越出 0.5°（仅激励段评估） | ≤1 | 视觉伺服不允许来回甩头（跟踪器易丢目标）；回位/入口过渡段混入换段瞬态，不参与该判据 |
| 稳态 \|β\| | 段末 5s 均值 | ≤0.5° | ≈8.8px@fx=1008，与跟踪器抖动同量级 |
| 指令纪律 | \|yaw_rate\| | ≤30dps | 配置限幅（FR-033） |

**垂直通道**（`step_vertical` 段，up +1/+3m 阶跃）：同上，α 与 vz（≤2.0m/s），
两处口径不同：**收敛上限 8.0s**（P-on-视线角为渐近收敛且姿态瞬态耦合限制增益
上限，vz_gain=0.1 实测 3.7~6.0s；见 `tracking_control_law.md` §7）；**变号反冲
阈值 1.0°**（α 噪声带由 SITL 姿态估计噪声 ±0.5° 决定，0.5° 阈值会误计）。

**距离通道**（`step_range` 段，N ±2.5/±5m 阶跃，d_exp=10m）：

| 指标 | 定义 | 验收值 | 理由 |
|---|---|---|---|
| 零过冲 | 全程 range_true ≥ d_exp − 0.3 | 硬判据 | d_exp 是拦截作业距离语义，冲过目标不可接受；d_exp 冻结后必须复核本项。**仅对"接近段"评估**（段起点射程 > d_exp + 0.5m）：目标向自机跳近（起点已在 d_exp 内）时射程天然 < d_exp，正确行为是后退重建射程，由收敛/稳态判据覆盖 |
| 收敛时间 | \|d−d_exp\|≤0.5m 保持 2s | ≤8.0s | 顶速 2m/s（控制器钳制）→ 纯位移 ≥2.5s + slew + 收敛余量 |
| 稳态误差 | 段末 5s \|d−d_exp\| 均值 | ≤0.3m | ki 应消静差；对齐双目测距精度量级 |
| vx 变号 | 段内有效变号次数（0.05m/s 死区 + 0.2m/s 反冲阈值） | ≤2 | 防积分极限环；反冲阈值滤零点噪声 |
| \|vx\| | **发布侧设定值**（控制器钳制后） | ≤2.0 | 意图侧上限是 approach_velocity_limit=3.0，钳制在 FlightController 属设计行为 |

**横切**（dwell_static + 全部 step 段）：意图占空比 ≥99%（无降级缺口）；
驻留段零刹车意图（kBrakeHover）。

## 关键实现点

- 分段键 = `phase` + 目标 NED 三元组（阶跃换位天然切段，CSV 无需额外标记）。
- 指标一律用**发布侧意图 + 注入几何真值**（β/α 由注入像素重算，与控制律
  `PixelToAngle` 同式）；遥测 NED 只用于 `range_true_m` 绝对量——不用遥测差分
  算加速度（2026-10-14 G2 教训：成簇/抖动会把 1.77 m/s² 测成 4.63）。
- 收敛判定要求"进入收敛带并保持 2s"，防单拍穿越误报。

## 排查要点

| 现象 | 排查 |
|---|---|
| "未找到该通道的阶跃段数据" | 剧本不含该通道（--tune-script）或段长 <100 行（驻留太短/提前中断） |
| 收敛时间恒为 0.00s | 阶跃未生效：查 CSV 的 target_* 列是否在段间变化（rig SetTargetNed） |
| β 稳态恒大 | cy/cx 内参与注入几何不一致（查装配期注入几何自检输出） |
| 距离段全部零过冲 FAIL 且 min≈d_exp−ε | 遥测与注入几何的系统性偏差，ulog 复核 trajectory_setpoint |
