# 地面站目标发送测试工具

## 功能职责

`tools/ground_station_target_update_tester.py`用于验证地面站目标位置最小闭环：

```text
Windows测试工具
→ 255/190 GCS心跳
→ MAVLink TIMESYNC响应/主动测量
→ V2_EXTENSION.message_type=65010 TRACK_TARGET_UPDATE
→ 香橙派GroundStationLink
→ GroundStationTarget Topic
→ V2_EXTENSION.message_type=65011 TRACK_TARGET_ACK
```

安全边界：

- 不发送PX4命令；
- 不切换模式；
- 不解锁；
- 不起飞/降落；
- 不发送setpoint；
- 不连接真实控制输出。

该工具只验证“目标消息是否被通信层接收/拒绝并ACK”，不代表飞机会执行任务。

## 使用前提

香橙派端必须已部署包含以下能力的`drone_control`：

- `GroundStationLink`启用MAVLink 2；
- 地面站来源固定`255/190`；
- 捕网-01目标地址`1/25`；
- `TIMESYNC`已实现；
- `TRACK_TARGET_UPDATE/ACK`使用`V2_EXTENSION.message_type=65010/65011`；
- `enable_control=false`。

香橙派启动：

```bash
cd ~/drone/gitee/drone_test
./build/drone_control
```

确认日志出现：

```text
地面站通信部件创建: ... aircraft=1/25 ... gcs=255/190 ... timesync=true
```

## 推荐测试

### 1. 合法目标

```powershell
D:\miniconda\python.exe tools\ground_station_target_update_tester.py `
  --connection udpout:192.168.144.12:19856 `
  --aircraft-system 1 `
  --aircraft-component 25 `
  --mode accepted
```

预期：

```text
TIMESYNC就绪: ...
测试=accepted ACK source=1/25 result=ACCEPTED reason=OK ...
```

### 2. 全部最小边界用例

```powershell
D:\miniconda\python.exe tools\ground_station_target_update_tester.py `
  --connection udpout:192.168.144.12:19856 `
  --aircraft-system 1 `
  --aircraft-component 25 `
  --mode all
```

当前`all`会依次发送：

| 用例 | 预期 |
|---|---|
| `accepted` | `ACCEPTED / OK` |
| `duplicate` | 第二条同序号应为`REJECTED_STALE_OR_DUPLICATE / UPDATE_SEQUENCE_STALE` |
| `wrong-address` | 无ACK |
| `expired` | `REJECTED_STALE_OR_DUPLICATE / TARGET_EXPIRED` |
| `invalid-lat` | `REJECTED_INVALID_FIELD / LATITUDE_OR_LONGITUDE_INVALID` |
| `bad-version` | `REJECTED_UNSUPPORTED_VERSION / PROTOCOL_VERSION_UNSUPPORTED` |
| `bad-flags` | `REJECTED_INVALID_FIELD / FLAGS_INVALID` |

注意：执行`bad-version`、`bad-flags`等拒绝用例不会启用控制。

## 常用参数

```text
--latitude 23.123
--longitude 113.123
--altitude-mm 120000
--alt-reference 1
--velocity-north-mps 1.2
--velocity-east-mps -0.5
--velocity-down-mps 0.0
--heading-deg 90.0
--horizontal-accuracy-m 1.5
--vertical-accuracy-m 2.5
--valid-for-ms 1000
--target-id 7
--boot-id <手动指定boot id>
--start-seq 1
--ack-timeout 3.0
--request-timeout 3.0
--minimum-sync-samples 5
```

目标`source_time_ms`由工具自动使用地面站本机`time.monotonic_ns()`生成，不需要手动填写；TIMESYNC offset只用于等待同步和诊断显示，飞机端会自行把地面站时间映射到飞机时钟。工具发送`TRACK_TARGET_UPDATE`时只发送`V2_EXTENSION`头部5字节加目标协议当前有效55字节，不发送满长249字节扩展payload，避免低速串口/数传桥对约266字节长帧处理异常。

## 香橙派日志观察

目标消息当前不会逐条打印成功日志，避免后续高频目标刷屏。建议看关键链路：

```bash
grep -E "地面站心跳|地面站时间同步|地面站通信" build/logs/*.log | tail -80
```

如果需要确认Topic发布，优先依赖Windows工具收到的ACK和开发机单元测试；后续若要实机观测Topic，可新增诊断订阅器，但不要在高频目标热路径加日志。

## 排查要点

- 没有`TIMESYNC就绪`：检查地面站心跳、HM30地址、防火墙、飞机身份和香橙派是否部署了新版本。
- `accepted`无ACK：检查工具是否使用`message_type=65010/65011`，以及香橙派是否运行新构建产物。
- `wrong-address`无ACK是预期行为，避免共享链路上非目标飞机响应。
- `REJECTED_TIME_SYNC_UNAVAILABLE`：说明飞机端尚未进入`SYNCHRONIZED`，先跑TIMESYNC工具或等待同步建立。
- `TARGET_EXPIRED`：说明`source_time_ms`映射到飞机时钟后剩余有效期不足。
- 确认安全门禁：始终保持`enable_control=false`，本工具也不发送任何控制类MAVLink消息。
