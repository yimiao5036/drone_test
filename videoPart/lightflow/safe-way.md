### 2.光流设计

此方案中的光流法由python层照搬，这个不一定最优后续还得优化

#### 2.1 流程

摄像头 → 网格点跟踪 → 复位筛选 → 分区统计 → 决策 → PID → 输出

#### 2.2 点管理

- **生成**：首帧均匀网格（25px间隔）
- **跟踪**：L-K金字塔光流
- **复位**（满足任一）：跟踪失败 / 漂移>30px → 回到初始位置
- **有效点**：跟踪成功且未复位，**仅有效点参与统计**

#### 2.3 风险计算

- **散度**：光流在径向的投影均值，正值=物体靠近
- **分区**：图像左/中/右三等分，独立计算风险

**刹车条件**：散度>0.8且光流>1.0 或 中心区域径向扩张>0.5

#### 2.4 决策

- 无风险 → 直行全速
- 中心风险较高 → 减速（可以考虑线性减速，以便于刹车）
- 左/右侧风险较高 → 方向往另一侧略微偏转（考虑采用 pid 计算）同时考虑降低飞行速度
- 中心风险较高 → 减速同时结合距离传感器判断是否要直接停下
- 左/右侧风险高 → 减速并考虑要不要偏转更多角度

#### 2.5 **PID**

    本部分参数相当重要，故一开始考虑全用保守策略
- 微分先行 + 低通滤波 + 抗积分饱和
- Yaw: Kp=1.2, Ki=0.1, Kd=0.05，输出[-0.8,0.8]
- Speed: Kp=0.8, Ki=0.05, Kd=0，输出[0,1.0]

#### 2.6 局限
- 光流无法区分远近（速度/距离耦合）
- 无IMU补偿，旋转可能误报

### 3.距离评估

本部分目前采用激光雷达用于获取精确的距离信息，用于紧急避险

#### 3.1 流程

激光测距 → 决策 → 输出

#### 3.2 决策

根据飞机当前速度实时判定安全距离（向上取整，仅个人想法）
